# 仿真台（可复现）

三套自测，全部直接编译 `../Tetris_text2.srcs/sources_1/new/` 下的**实时源码**（改完 RTL 直接重跑即可），
产物写到各自的 `build/`（已在 .gitignore 中忽略）。

## 一键跑全部

```
sim\run_all.bat
```

输出最后会给 SUMMARY：三套分别打印 `=== ALL PASS ===` 或 `=== FAILED n ===`。
单套日志在 `sim/logs/<套名>.log`。

## 三套分别是什么

| 套 | 顶层 | 覆盖内容 | 预期项数 |
| --- | --- | --- | --- |
| `sim/duo` | `duo_tb` | Playfield 级双人：出生列(8/16)、两片互撞与"顶住不锁存"、硬降停对方方块、被挡时不显示幽灵、22/23 列与顶部旋转无 X、共用 Hold、单流随机(同拍分配/每局搅动)、双人时间阈值、整行 24 格消行、2px 死区 | 65 |
| `sim/frame_duo` | `frame_duo_tb` | frame 级显示：P2 方块/落格取色、24 列右侧格子、Next 盒子与中间虚线位置、P2 下一块预览、Hold 盒子位置、2px 死区取色、左边框不出头、单机 P1 显示回归 | 22 |
| `sim/level` | `net_level_tb` | 单人回归：加分系数、分数/时间等级阈值、等级重置、每级自动下落速度 | 26 |

## 单独跑一套

```
cd sim\duo
run.bat
```

## 说明

- ROM（Tetromino / weiyibiao / number / letter）在仿真里用**桩**（组合读、全 0 或合成形状），
  因此这里验证的是逻辑通路；要按真实方块形状验证，可把工程 IP 的 `*_sim_netlist.v` 换进来。
- `sim/level` 里 `frame` 的 `duo` 固定接 `1'b0`（单人回归）。


## 面积优化实测记录（Duo 之后）

全设计（`Flow_AreaOptimized_high` 策略）：**LUT 19115 (91.9%) → 16178 (77.78%)**，FF 4688、BRAM 14/50、DSP 5、F7 Muxes 1871、LUT-as-Memory 5 位。

各步模块级（Playfield 单模块综合，Default 指令）：

| 步 | 内容 | LUT | Δ |
| --- | --- | --- | --- |
| 起点 | — | 9956 | — |
| A | 场地查表改行字（逐位等价） | 10306 | +350 |
| B | 互撞改"先比行再比列" | 9105 | -1201 |
| C | 编号一维分离 + 哨兵修复 | 8580 | -525 |
| D | 消行行满改或归约 | 8140 | -440 |
| F | 随机：32 位 LFSR + 同拍分配 + Idle 搅动 | 8274 | +134 |

**注意（A 步的坑）**：模块级用 Default 指令测 A 是 +350，但在**实际使用的 `Flow_AreaOptimized_high` 策略下**，
带 A = 全设计 **16178**、去掉 A = **18625**（回退 A 反而多 2447 LUT）。结论：**A 必须保留**；
优化效果要按最终使用的综合策略来评估。
