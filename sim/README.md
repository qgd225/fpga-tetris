## 说明

- ROM（Tetromino / weiyibiao / number / letter）在仿真里用**桩**（组合读、全 0 或合成形状），
  因此这里验证的是逻辑通路；要按真实方块形状验证，可把工程 IP 的 `*_sim_netlist.v` 换进来。
- `sim/level` 里 `frame` 的 `duo` 固定接 `1'b0`（单人回归）。
- `sim/duo` 里有一条**全程核查**：每个时钟沿比对 `state`(镜像) 与 8 份 `state_ram` 副本是否逐位一致；
  只有第 19 组『只写副本』那几行会临时关掉（那组就是故意只写副本）。


## 面积优化实测记录（Duo 之后）

全设计（`Flow_AreaOptimized_high` 策略）：**LUT 19115 (91.9%) → 16178 (77.78%)**，FF 4688、BRAM 14/50、DSP 5、F7 Muxes 1871、LUT-as-Memory 5 位。

各步模块级（Playfield 单模块综合，Default 指令）：

| 步 | 内容 | LUT | Δ |
| --- | --- | --- | --- |
| 起点 | — | 9956 | — |
| A | 场地查表改行字（逐位等价） | 10306 | +350 |
| B | 互撞改"先比行再比列" | 9105 | -1201 |
| C | 编号一维分离 + 哨兵修复 | 8580 | -525 |
| D | 消行行满改或归约 | 8140 | -440 |
| F | 随机：32 位 LFSR + 同拍分配 + Idle 搅动 | 8274 | +134 |

**注意（A 步的坑）**：模块级用 Default 指令测 A 是 +350，但在**实际使用的 `Flow_AreaOptimized_high` 策略下**，
带 A = 全设计 **16178**、去掉 A = **18625**（回退 A 反而多 2447 LUT）。结论：**A 必须保留**；
优化效果要按最终使用的综合策略来评估。


## 场地改 LUTRAM 行字副本（B2 步实测）

做法：`state`(480 位 FF) 仍是主存储与对外接口，另挂 **8 份 24×20 行字副本** `state_ram[0:7][0:19]`
（分布式 RAM，单读口一拍一行，分工固定：0/1=P1 渲染下行/本行、2/3=P2、4/5=幽灵、6/7=旋转），
所有场地判定改读副本；三条写路径（清场/落锁/消行搬移）统一走一个『行写口』，一拍拍一行，
镜像与 8 份副本**同拍写同一行**。消行搬移由『1 拍整体搬』改成『20 拍逐行搬（行号降序）』，
`frame.v` 的 `state_color` 跟着 Playfield 导出的 `mv_we/mv_row` 同步搬（原来 frame 里另有一份 1 拍搬移，
必须一起改，否则颜色与场地会错位）。

全设计（`Flow_AreaOptimized_high`，synth 口径）：

| 资源 | 改前 (d6ad912) | 改后 (B2) | Δ |
| --- | --- | --- | --- |
| Slice LUTs | 16062 (77.22%) | **11822 (56.84%)** | −4240 |
| LUT as Logic | 16057 | 11689 | −4368 |
| LUT as Memory | 5（全是 SRL） | 133（**128 分布式 RAM** + 5 SRL） | +128 RAM |
| Slice Registers | 4683 | 4700 | +17 |
| F7 Muxes | 1900 | 1685 | −215 |
| F8 Muxes | 540 | 293 | −247 |
| Block RAM | 14 | 14 | 0 |
| DSP48 | 5 | 3 | −2 |
| Bonded IOB | 34 | 34 | 0 |

模块级（同一次综合，`report_utilization -hierarchical`）：

| 模块 | 改前 LUT | 改后 LUT | Δ |
| --- | --- | --- | --- |
| `Playfield` | 10503 (1034 FF) | **6728**（6600 逻辑 + 128 LUTRAM，1057 FF） | −3775 |
| `frame`（含子模块） | 12851 (2679 FF) | 9036 (2702 FF) | −3815 |
| `hdmi` | 1155 | 1167 | +12（跑动噪声） |
| `net_screen_tx` | 1047 | 1040 | −7（跑动噪声） |

结论：**Playfield 本身 −36%**，全设计 **LUT 77.2% → 56.8%**，多出来的 128 个分布式 RAM 落在
`LUT as Memory` 里（不进 LUT 逻辑账）；FF 只多 17 个（行写口的状态位）。
