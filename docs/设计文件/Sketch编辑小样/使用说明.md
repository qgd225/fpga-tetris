# Sketch 可编辑小样

本次仅保存本地，不提交 Git、不推送 GitHub。该文件用于验证设计文件导入和手动编辑，不作为 Tetris 游戏 UI 参考图，不改变硬件源码、正式资产或比特流。

## 导入与编辑

1. 在 Pixso 的文件导入窗口选择 Sketch，导入本目录的 `可编辑界面小样.sketch`。
2. 打开页面“可编辑设计小样”和画板“01 可编辑界面小样”。
3. 展开左侧图层列表，选中“页面标题”后修改文字。
4. 展开“主要按钮”，分别选择“按钮背景”和“按钮文字”，修改颜色或文案。
5. 移动“内容卡片”分组，再进入分组调整内部文字和矩形。
6. 选择“可替换图片素材”，检查能否移动、缩放，以及能否通过 Pixso 的图片操作替换素材。

文字没有转曲，按钮没有合并为图片，所有图层均未锁定。图片自身是位图素材，其内部色块不作为独立矢量形状编辑。小样只使用普通分组，没有声明自动布局、组件实例或交互连线。

字体指定为 `MicrosoftYaHei`（微软雅黑）。若 Pixso 提示字体缺失，请替换为本机可用的中文字体。文字位置、圆角和图片替换的最终表现以实际导入为准。

`辅助预览.png` 是根据文件内图层数据绘制的辅助示意，不是 Pixso 截图，也不是游戏 RTL 预览。`结构检查.json` 记录文件检查及尚待验证的事项；结构检查通过不等于实际导入已经通过。

## 重新生成

工具目录：`D:/vivado_project/Tetris/tools/sketch-editable`。

```powershell
cd D:/vivado_project/Tetris/tools/sketch-editable
npm.cmd ci --ignore-scripts --no-audit --no-fund --cache D:/vivado_project/Tetris/temporary/sketch-editable/npm-cache
npm.cmd run generate
python inspect.py
```

`inspect.py` 使用 Pillow；本次环境已具备。`sample.json` 可以调整标题、说明、强调色、按钮文案及两张卡片的内容。当前布局固定为两张卡片，不应直接增减卡片数量；布局需在 `generate.cjs` 中修改。默认重新生成会覆盖小样，手动编辑后的文件请在 Pixso 中另存。

## 开源来源

生成依赖：[amzn/sketch-constructor](https://github.com/amzn/sketch-constructor)，固定 npm 版本 `1.26.0`，采用 Apache-2.0 许可证，依赖完整性记录见工具目录 `package-lock.json`。第三方包原有 LICENSE、NOTICE 及版权声明保留在安装包中，未改动上游源码。

该库通过生成 Sketch 工程结构工作，不需要安装 Sketch。导入 Pixso 后的兼容性仍待实际验证。

本地生成脚本针对上游流式打包的中文编码问题，使用 `jszip@3.10.1` 显式以 UTF-8 重写 JSON 条目，并回读检查中文页面名称；未修改第三方库源码。JSZip 采用 MIT 或 GPL-3.0 双许可证，本工具按 MIT 许可证使用。

同时显式同步图层文字样式和字符样式，避免上游重复构造样式造成字号、字体和颜色不一致；结构检查包含该一致性检查。
