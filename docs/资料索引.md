## 方案采用后的同步

1. 新提议、取舍与实施步骤写入 `docs/计划书/`；未采纳或未实施内容保持方案身份。
2. 执行计划时，将已采用的新设定写入故事文件，实际玩法与参数写入玩法规格，工程规则写入 AGENTS.md，版本与使用变化写入 README。
3. 核心文件分别标明“已确认待实现”与“已实现”，不能用故事设定或计划完成度代替代码实现、验证和发布状态。
4. 收尾核对核心文件、实际采用配置与验证状态；已同步的计划只负责解释改动原因及过程，不能要求读者回看计划书才能获得当前完整规则。
