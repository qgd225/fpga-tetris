# 比特流存放规则

- 两个开发工作区保留：`Tetris` 和 `Tetris_hdmi`。
- 本机统一下载位置：`D:/vivado_project/Tetris/bit/Tetris.bit`。
- `Tetris_hdmi/bit` 是指向上述目录的 Windows 目录联接，不占用第二份文件空间。
- Git 只跟踪 `bit/Tetris.bit`。更新后需在对应分支执行 `git add bit/Tetris.bit` 并提交、推送，Git 不会自动上传。
- Vivado 的 `impl_1` 已设置 `write_bitstream` 完成后发布钩子。脚本构建和界面生成均覆盖同一个发布文件；内部 `.runs` 为构建缓存。
- 两个分支同时构建时，最后完成发布的版本覆盖前一个版本；下载前确认构建日志中的 `LATEST_BITSTREAM`。
- 在其他电脑克隆后，无需目录联接：发布脚本在没有同级 `Tetris/Tetris.xpr` 时使用当前工程的 `bit` 目录。
- 旧工程的源码、Git 记录和历史比特流已压缩保存在 `D:/vivado_project` 的归档 ZIP 内，未纳入源码仓库。
