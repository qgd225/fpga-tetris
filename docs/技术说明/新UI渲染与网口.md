# 新UI渲染、存储与网口实现

当前版本为 2026-10-29 NEXT/HOLD 预览 ROM 无损优化版，资源与发布状态见 `reports/rom_optimization_20261029`。画面沿用导管、背景与船板细化版，本轮未重新生成预览。旧阶段及视觉报告保留其当时状态。

## NEXT/HOLD 预览小 ROM 优化

预览仅使用 `shape_rom.coe` 中各类型的初始姿态。`spawn_shape.vh` 提供七种原始坐标，NEXT 两路和共享 HOLD 各保留零初始化及两拍寄存输出，与原 IP 的实际行为一致。三份 18 Kb 块 RAM 被小型查表逻辑替代；场地、碰撞、旋转和智能提示的原 IP 不变。原始 IP 模型对照与最终功能回归均通过；整机释放 1.5 块 36 Kb 等效 BRAM，并减少 94 LUT。

## 五拍像素链

`story_ui`只转发真实状态并增加最后一拍。`reference_ui_renderer`统一合成船壳、基础场地、材质、字形与覆盖层；材质和文字各三拍，合成第四拍，输出第五拍。坐标、有效标记和颜色同时推进，不改变原有前取像素相位。游戏规则、碰撞、HOLD交付、计分和胜负逻辑保持原样。充能/残骸轨的状态阈值提前一拍寄存，利用帧边界与可见区之间的间隔，不增加像素输出拍数。方块部分将几何/类型选择与着色分拍，五拍输出时序保持不变。

`assets/new_ui/renderer_source.v.in`为可编辑的文字描述源，`tools/build_ui_text_templates.py`生成正式渲染器、字符模板ROM和字节布局清单。固定字符入共享ROM，动态BCD数字保留原来源。字库统一5×7，按声明的字符步距和高度采样；同组标签与数值共用基线。结算统一为标题、关卡/模式、副标题下的单列统计、实心选中按钮。

## 材质与容量

不在芯片中保存五张整屏预览ROM。`build_ui_material_atlas.py`将重点模块分为8×8图块，按颜色复杂度选择常量、1/2/3/4位局部索引或全局直接索引；保留透明与锁链前半圈标记。描述符、图案、局部颜色索引各一级同步存储，全局RGB表提供完整颜色。编码/解码不再额外降低受控近色后的精度。

短尾段按真实深度切分；短小尾段按真实容量选择分布式ROM，声音末尾短块采用分布式存储；材质的较大尾段保留BRAM以减小LUT与布线压力。声音按九个原始ADPCM半字节打包为36位字，保留原始样本、播放时序与一拍读延迟；全地址和独立PCM解码测试核对数据。

容量不足按D1星空/漂浮残片、D2非功能磨损/重复纹理、D3额外装甲/支架/无功能走线裁减。连续船壳与功能边框保留。未实施E类动态削减：保留充能沿管推进、核心扫光、ONLINE呼吸、消行火花及真实加成跳字。外围简化意味着整幅图不与原参考完全一致，五组重点稳态像素单独保护。

## 状态与模式

- LOCKED按正式残骸阈值，六圈铁索从上到下连续缠绕；前半圈覆盖玻璃和侧轨。
- 闯关八段由正式核心进度控制，琥珀底座不占电芯；成功才亮第八段。
- 四阶从下到上依次为RECONNECT、REBUILD、STABILIZE、RECHARGE，圆环在上，名称在下。
- 无尽使用真实RESERVE，不显示闯关导管。图形智能落点仅单人显示。
- 消行跳字来自`batch_commit/batch_n`的只读观察：四行记六，其他批次保持原真实加成；暂停冻结年龄，新开局清除。
- 导管推进、玻璃扫光读取已有`charge_left`事件寿命，ONLINE呼吸读取动画相位；均不回写游戏状态。

## RGB888网口

新FPGA发送类型4的RGB888游程包，保留旧按键类型3。旧行包类型1和调色板类型2仅在PC端继续兼容，新画面不再经过固定56色色号截断。

| 字段 | 字节数 | 含义 |
| --- | --- | --- |
| A5 5A 04 00 | 4 | 魔数、类型、版本 |
| frame / line / x / width | 各2 | 大端帧号、行号、起点、覆盖像素宽度 |
| run / R / G / B | 每段4 | 长度1～255，RGB各8位 |

每包最多320段游程、UDP载荷最多1292字节，始终在标准MTU内。一行可变分为1～4包，实际覆盖宽度在头中给出。像素域先压缩，经Gray指针异步FIFO进入125MHz发送域；描述符在数据写完后发布，发送器保留MAC所需的包间等待。溢出/下溢置故障并停止后续发包，不继续发送损坏画面。

PC按实际像素区间累计行覆盖，完整覆盖后标记该行就绪；支持65535→0帧号回绕并丢弃迟到旧帧。RGB图像直接生成Pillow RGB帧，旧索引图仍使用P模式。键盘和网络配置流程保持不变。

已验证实际分包、双时钟FIFO、UDP/IP、CRC32与本机UDP接收；板上RGMII电气链路、HDMI、实机收流、操作与试听仍待用户上板。


## 布线时序修订

为断开游戏碰撞/交接组合链到音效优先级仲裁的长路径，在Tetris顶层将所有音效事件、数量和取消信号整体寄存一拍，保持同一时刻事件的相对关系。该寄存器只送音效，不能回写游戏状态。5万组随机事件、优先级与取消序列对原仲裁器延后一拍比较通过；语音内容及解码样本保持原样。

新渲染不读取落定块owner显示位，综合可裁掉该未使用位；三个方块类型位、游戏占用与24列双读口保持完整。物理检查接受144个类型RAM位或192个类型+owner位，逐列逐位核对写地址、数据、时钟、使能和两套读地址，不放宽游戏位图的768位检查。Vivado重建层次重命名的端口按真实驱动关联核对。

新FIFO指针偏斜约束使用仅实施阶段读取的late XDC，覆盖两个跨域FIFO的两个方向；不改变目标时钟，不增加掩盖同步路径的例外。完整布线以后检查四条新增约束是否确实出现并满足8ns上界。

## 字段与边界复核（2026-10-29）

当前选船固定显示四行SHIP 01～04，直接以level_id高亮；保留旧偏移接口但渲染不读取。成功结算保留CHARGE、TIME、RANK、AVG BATCH；失败使用LINK LOST，仅列CHARGE、TIME、DEBRIS，已经完成的任务仍划线；无尽只列SCORE、LINES、TIME，按钮为RETRY/MENU。SHIP是统一副标题，不增加重复统计行。超过两位数的记功用完整六位BCD表示，不把实际值饱和为99。跳字观察宽度为五位，避免批次加成被三位字段截断。

文字原点差值保留十二位，寄存后再判断裁剪范围；负坐标和超过有效高度的字形不回绕到画面。组件测试包含这两种边界。储备预警使用真实1/2Hz相位；回充截断显示实际加成和MAX，满储备且没有收益时只显示MAX。无尽短时回充条纹、升速提示均读取现有事件寿命，不改变储备计算。

物理RAM接线检查允许Vivado复制同一组合反相信号：按LUT真值表和逐输入逻辑递归证明原驱动与复制驱动等价；寄存器、存储和输入端仍要求精确身份，不按名称猜测。保留A2接到A1的故意错线负例，确认检查器会拒绝。

PC解码使用标准库struct按四字节游程解析，逐段检查非零长度与总宽度，等价生成原RGB序列。接收端在250ms没有接纳有效帧之后允许重新建立帧号基准，处理FPGA复位后的帧号回退；正常连续收流仍拒绝迟到旧帧。完整四帧像素与本机UDP、同一接收进程中的复位恢复均有独立通过记录。实际帧率、网卡和物理链路由用户实测，不用离线解码速度替代。

## 布局与背景修订（2026-10-29）

新增ui_layout_geometry.vh集中定义核心右移24像素、状态牌y=584及完整飞船预览位置。核心在统一虚拟源坐标取原材质和动态；导管只对直管段做24像素延长，出口固定，竖段和末端与核心一起平移。P2原底材的导管残片按既有移除mask从无尽底材补齐。四阶段清除底材旧箭头后重画朝上的三角，最上阶段不再裁掉尖端。

选船固定四行，以level_id高亮，不再使用menu_offset决定可见船号；状态机接口保持兼容。飞船预览通过分布式一位轮廓mask复用现有船况头图集RGB，比例和像素保持原样，不新增整幅图像ROM。无尽模式的文字底板缩至左侧64像素，ENDLESS使用同一字库的紧凑步距，完整船头不再被文字底板遮住。

外围背景采用静态坐标星点，船壳增加连续开放接缝、少量螺栓和通风槽，使用既有颜色；不读取动画计数器、不增加逐帧纹理或整屏位图。最终结果以本轮ui_layout_20261029报告和20261029_UI布局与背景修正RTL目录为准，旧发布报告保留原始状态。

飞船轮廓查表与材质描述符寻址并行：图集地址只由预览框与坐标决定，透明轮廓使用截短的行列地址、常量移位加法和三拍有效位，与图集输出同拍合成。轮廓不再串在描述符BRAM地址前，五拍对外延迟保持原样；同步修正原有frame／level测试的核心探测坐标，共用UI_CORE_CENTER_X。保留调整前的37帧原始RGB指纹，调整后重出37帧做整帧一致性复核。

用户随后要求更换左上行星，当前使用assets/new_ui/blue_planet.png的原生像素素材：64×64、15个可见颜色加透明，以2倍整数采样显示。build_ui_planet.py无损生成4096项四位索引和16项RGB，合计16768位，使用分布式ROM；右下卫星保持小型轮廓表方式。新的行星替代前述规则地表着色，不使用整屏图片。材质短尾段分布式阈值提高到24576位，当前用于3位图案库的短尾，以解决阶段50.5 BRAM容量，读取时序及像素不变。最终LUT余量及布线以新报告为准。

## 导管接头与外围细化（2026-10-29）

补槽后仍有一段P2旧面板斜角被烘焙进导管RGB：源坐标x1110～1113、y148～183侵入玻璃与橙管。表面编译器现从完好玻璃和直管取完整横向截面，重建y151～156的水平金属接箍，再接等宽橙管；目标坐标仍由UI_CORE_DX映射，未移动重点组件。新增独立像素断言检查玻璃宽度与橙管左侧高光，防止自生成期望图掩盖残片。

按用户顺序先修导管，再补背景，最后补船板。背景在原有行星／卫星外增加左侧静态流星与两颗小行星；小行星采用32×32六色原生图，共享1024项三位索引与八项RGB，合计3264位分布式ROM，不增加BRAM。两种显示尺寸均为整数尺度，小图作水平镜像。流星为静态渐暗尾迹，未新增动态计数器。

船板增加与原边缘相接的开放接缝、两组嵌入式通风槽及少量轨道固定件，不增加装饰框。原生重点材质、所有现有动态及五拍像素输出保持不变；颜色仍由原有RGB888链路传输。普通构建仅依赖已冻结PNG与本工程编译器，制作过程的pixel-art-studio不是构建依赖。最终发布及输入证据另见ui_polish_20261029报告，不用此前报告代替本轮验证。
