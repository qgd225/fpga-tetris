# 双来源双人控制与接线

更新：2026-10-31。P1 可使用引脚第一组或 PC 的 WASD＋Q；P2 可使用引脚第二组或 PC 的方向键＋小键盘0。同一玩家的两种来源先合并电平再生成边沿，支持同一台电脑双人、双引脚按键双人及两种混合组合，无需选择输入设备。单人仍兼容方向键＋小键盘0操作P1，第二组引脚不参与单人游戏。Enter／小键盘5开始或暂停，Esc直接返回，F12／小键盘9复位；引脚switch与复位仍共用。

## PC键位

| 操作 | P1 | P2 |
| --- | --- | --- |
| 左／右 | A／D | ←／→ |
| 旋转／下落 | W／S | ↑／↓ |
| HOLD | Q | 小键盘0 |

下落维持原有短按释放／长按加速手势。双人HOLD在合并后的按下边沿执行；单人短按松开执行HOLD，长按约300ms切换提示。菜单／结算可由两组玩家左右键操作；两边同时请求时仍遵循现有状态机优先级。

窗口必须有焦点。失焦、退出及约200ms未收到完整按键包会取消PC输入，不把清除状态当作硬降、短按HOLD或确认。输入来源不涉及两台电脑的独立网络会话；同一台电脑用两组键位完成双人控制。

## 外接按键

全部低电平有效，按键一端接信号、另一端接GND。保留原引脚；第二组使用GPIO1排针P2的五个空闲信号，依据[排针定义](../学习资料/BX72_排针定义.md)。**排针连接器P2与游戏玩家P2是两种编号。**

| 玩家／用途 | 顶层端口 | FPGA球位 | GPIO1排针位置 |
| --- | --- | --- | --- |
| P1左 | left | F13 | P2-1（GPIO1-0） |
| P1右 | right | E13 | P2-3（GPIO1-2） |
| P1下落 | drop | D14 | P2-5（GPIO1-4） |
| P1旋转 | rotate | F16 | P2-7（GPIO1-6） |
| P1 HOLD | hold | AB18 | 沿用原接线，非本表GPIO1信号 |
| P2左 | left2 | F14 | P2-2（GPIO1-1） |
| P2右 | right2 | E14 | P2-4（GPIO1-3） |
| P2下落 | drop2 | D15 | P2-6（GPIO1-5） |
| P2旋转 | rotate2 | E17 | P2-8（GPIO1-7） |
| P2 HOLD | hold2 | D16 | P2-10（GPIO1-9） |
| 公共开始／暂停／长按返回 | switch | P20 | 沿用原接线 |
| 公共复位 | Reset_key | V17 | 沿用原接线 |

GPIO1连接器第12、30脚为GND。第11脚是5V、第29脚是3.3V，不能误当信号或接地。所有按键输入都配置LVCMOS33与内部上拉，不接按键时由上拉维持未按下电平；不能据此认为任意未配置的输入都能直接悬空。长线手柄建议在板端增加外部上拉，避免干扰。外部设备与开发板共地，不向输入施加5V。

P1/P2均经过同步、消抖。同一玩家多个来源同时按住相同操作时，直到最后一个来源松开才产生释放边沿；不会因为另一来源的松开而触发硬降。方向连发继续采用现有DAS／ARR及双方向暂停连发规则。取消PC状态时允许原本由本地按住的下落键正常释放。

## UDP按键协议

新格式固定5字节：`A5 5A 05 B1 B2`，每20ms重发完整状态，按下／松开也立即唤醒发送。

| 字节 | 位 | 含义 |
| --- | --- | --- |
| B1 | 0／1／2／3／4 | P1左／右／下落／旋转／HOLD |
| B1 | 5／6 | 公共开始暂停／复位 |
| B1 | 7 | 取消，两名玩家及公共按键全部清除，抑制释放动作 |
| B2 | 0／1／2／3／4 | P2左／右／下落／旋转／HOLD |
| B2 | 5 | 直接返回，按下边沿执行 |
| B2 | 6／7 | 保留，发送0 |

只有B2收齐后才同时提交两名玩家状态。残缺包不更新任何玩家，字节间超时后重新寻找包头。保留`A5 5A 03 B`旧格式，低五位作为P2输入，5／6为公共开始暂停与复位；旧PC在双人控制P2、单人控制P1。新PC必须配套新版固件，旧固件不识别类型5。

核心逻辑、玩法、画面与音频规则不因输入来源改变。发布与验证结果见[本轮报告](../reports/dual_input_20261031/README.md)，实际按键电气、键盘多键冲突和物理网口仍需上板验证。
