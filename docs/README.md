## 当前功能

四入口为 `SOLO ENDLESS`、`DUO ENDLESS`、`SOLO CAMPAIGN`、`DUO CAMPAIGN`。单人场地 20×20，双人 24×20；双人共享场地、HOLD、核心与结算。

- 无尽按有效游玩时间每 45 秒升一档，315 秒达到第 8 档后持续。RESERVE 初值 90、上限 150 单位，每秒消耗 1，每批真实消行 n>0 回充 `24+12n+(n==4?24:0)`；顶出或供能耗尽失败。
- 闯关先选 `SHIP 01`～`SHIP 04`，四关全部开放。清除残骸并达到本船记功目标才成功；四行记 6，胜利结算按批次与时间评 S／A／B／C；核心区分 LOCKED、HALF、ONLINE，游戏与结算不显示 SCORE。
- HOLD 存入受每块一次、单人 3／双人 2 次落定及 2 秒冷却限制；取出采用预约，不受存入冷却限制，当前块落定并结束消行后交付且不消耗 NEXT。未预约暂存寿命 30 秒，预约冻结原余量、取消恢复。固定三格显示存入条件。
- 单人无尽提示不限次，单人闯关按核心进度管理额度，单次 12 秒；剩余／上限及有效期以图形展示。双人隐藏提示，完整保留 P2 NEXT。
- 保留七种方块、旋转、软降／硬降、NEXT、幽灵与单人智能落点。64 套残骸模板允许覆盖洞，镜像配对且可复现。
- HDMI 同时输出画面和音频；程序化音效、配乐及语音共用音频链路，蜂鸣器端口静音。PC支持RGB888游程画面、混音PCM及键盘遥控，保留旧行包／调色板兼容；音频发布状态见本页。

## 工程与启动

| 项目 | 值 |
| --- | --- |
| 正式工程 | `D:/vivado_project/Tetris/Tetris.xpr` |
| 工具／器件 | Vivado 2018.3；`xc7a35tfgg484-2` |
| 顶层 | `Tetris` |
| 显示 | HDMI TMDS，1280×720；实际像素时钟约 74.219 MHz |
| 音频 | 48 kHz、16 位、双声道 LPCM |
| 手写 RTL 编码 | 本机 GBK，无 BOM；Git 提交 UTF-8，见[源码编码说明](技术说明/source-encoding.md) |

1. 使用支持 `.gitattributes` 编码属性的 Git 检出工程。
2. 双击 [tools/打开工程.bat](../tools/打开工程.bat)，或用 Vivado 2018.3 打开 `Tetris.xpr`。
3. 本轮对冻结正式资产的完整复验入口为 `python tools/run_spawn_optimization.py`；旧资产生成入口仍有 56 色网口断言不兼容问题，见本轮报告。原本机统一构建入口为 [tools/生成bit.bat](../tools/生成bit.bat)，详细用法见 [tools/README.md](../tools/README.md)。结束仅显示是否通过、时序指标、bit／bin保存路径；详细日志保存在 `temporary/build_candidates/`。
4. 可直接下载 `bit/Tetris.bit`；Flash固化使用配套 `bit/Tetris.bin`，实际Flash型号和启动模式按板卡选择。仅补生成bin运行 `tools/生成bin.bat`；未来验证通过的发布入口同步更新bit/bin。重新生成时遵循 AGENTS.md 的验证和发布要求；IP 输出由工程配置重新生成。

## 操作与 PC 端

| 板载输入 | 引脚 | 当前用途 |
| --- | --- | --- |
| `left`／`right` | F13／E13 | 游戏中左右移动；菜单中切换选项 |
| `rotate`／`drop` | F16／D14 | 旋转／加速下落 |
| `hold` | AB18 | 短按 HOLD；单人长按切换智能提示 |
| `switch` | P20 | 菜单短按确认；游戏短按暂停／恢复，长按返回 |
| `Reset_key` | V17 | 复位 |

P1 可使用引脚第一组或 PC 的 WASD＋Q；P2 可使用引脚第二组或 PC 的方向键＋小键盘0。同一玩家的两种来源先合并电平再生成边沿，支持同一台电脑双人、双引脚按键双人及两种混合组合，无需选择输入设备。单人仍兼容方向键＋小键盘0操作P1，第二组引脚不参与单人游戏。Enter／小键盘5开始或暂停，Esc直接返回，F12／小键盘9复位；引脚switch与复位仍共用。接线和协议详见[双来源双人控制](技术说明/双来源双人控制.md)。完整规则及结算选项见[玩法规格](游戏模式_玩法规格.md)。

PC 使用方法：网线直连 FPGA 与有线网卡，PC 使用 `192.168.0.3/24`，FPGA 为 `192.168.0.2`；双击 [TetrisPC.exe](../TetrisPC.exe)。程序内置运行环境；静态 ARP 需要修复时出现 UAC 提示。取消提权可能导致 PC 按键无法传达。网卡必须显示已连接，USB 网卡需要正确驱动。故障日志在 `%LOCALAPPDATA%/TetrisPC/Logs/`；开发备用入口为 `pc/Python备用启动_需要Python.bat`。

PC 工具更新（2026-10-31，便携版 2026.10.31.1），现附 [无板网口自测说明](../pc/README.md)：双击 `pc/网口自测.bat` 可选本机回环、外部监听和对端发送；内置自测不需要 Python。回环通过不代表实际网线或外部入站已验证。
