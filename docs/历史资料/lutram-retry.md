# 场地 LUTRAM 重试

本分支将场地动态判定读取迁入 LUTRAM，保留原 `state[479:0]` 作为规范镜像。HDMI、网络发送和玩法规则不变。

## 结构

- 八类读口：双方当前行、下方行、幽灵行、旋转预判行。
- 每类有四个并行格子，各格拥有独立读地址，共 32 个 `board_row_replica` 实例。
- 每实例使用 24 个 `RAM32X1D`，总共 768 个逻辑 RAM 原语。综合展开时报告 1536 个存储 LUT，首轮实现优化后为 768 个；LUTRAM 也计入总 LUT。
- 所有副本与规范镜像共同接收唯一的 `row_we/row_addr/row_data` 事务，异步读取、时钟沿写入。
- 上电、进入 Idle、结束页重开时逐行清零；持续约 20 拍，即 0.27 微秒。期间冻结运动、旋转和结束判定。
- 双人同时锁定时，先提交 P1，P2 保留首格请求和当前索引，待写口可用后继续，避免丢格和重复提交。
- 消行从目标行向第 0 行逐行搬移，`frame` 的颜色、归属使用同一 `move_we/move_row` 提交。
- 消行检测在初始化、搬移或任一方锁定尚未完成时关闭，避免对半成品场地再次触发消行。

历史脚本把循环临时行号接到循环外的共享读口，存在四格实际读取同一行的风险。此版本不使用该写法，也不依赖三维数组 RAM 推断。

## 验证

运行 `sim\run_all.bat`，包含原有九套测试和新增 `lutram`。测试失败或编译错误会返回非零退出码。

新增测试分别使用行为模型和 Xilinx UNISIM `RAM32X1D` 模型，覆盖：

- 随机行写入时，32 个读口与规范镜像逐拍一致。
- 四格位于四个不同行，且各行数据不同，验证读地址真正独立。
- 双人同时锁定、P1 抢占 P2 的部分锁定后恢复，双方各四格全部提交，P2 等待请求最终清空。
- 结束页重开和仅一拍的 Idle 请求仍能完成全部行清零。
- 单行消除、两行连续压缩及顶行补零。

每种模型完成 21,536 次读出口与镜像比较。另在构建临时副本中故意把四格当前行读地址改成共用第一格地址，四行定向断言稳定检出 3 项失败；正常版本两种模型全部通过。这个负对照未修改正式 RTL。

`frame_storage_tb` 使用 Xilinx 原语模型，34 项断言联合检查双方锁定及消行后，占用状态、颜色和玩家归属一致。形状 ROM 使用时钟读出测试桩；预览几何使用原显示回归的零偏移桩，不参与这套存储断言。

最终 `sim\run_all.bat` 返回 0：原有九套共 784 项检查通过，两个场地模型均通过，显示存储联合断言全部通过。测试汇总位于 `sim/logs/lutram_regression_summary.log`。

旧测试台通过真实行写事务清场，避免仅强制清空镜像后留下旧 RAM 数据；显示回归在启动时等待初始化完成。

完整构建：

```powershell
& D:\xilinx\Vivado\2018.3\bin\vivado.bat -mode batch -source tools\check_lutram.tcl
```

脚本复制项目到 `Tetris.runs/lutram_final/`，在副本中综合和实现；不会覆盖根目录 `Tetris.bit` 或原 `synth_1/impl_1`。报告和候选比特流保留在该目录。

综合后与实现后运行 `tools/check_lutram_pins.tcl`，核对全部 RAM 的写地址、数据、时钟、使能，以及独立读地址到模块端口的连接。

## 构建结果

2026-10-23，Vivado 2018.3，`xc7a35tfgg484-2`，综合指令 `AreaOptimized_high`，沿用原工程实现策略。以下为最终源码完整布局布线后的结果，包含 LUTRAM 本身的开销：

| 指标 | 原发布版本 | 本次实现 |
| --- | ---: | ---: |
| 总 LUT | 20,293 / 20,800 (97.56%) | 17,272 / 20,800 (83.04%) |
| 寄存器 | 6,273 | 6,261 |
| Block RAM | 15.5 / 50 | 15.5 / 50 |
| DSP | 4 | 2 |
| WNS | +0.251 ns | +0.117 ns |
| WHS | +0.067 ns | +0.097 ns |

总 LUT 净减少 **3,021 个，约 14.89%**，利用率降低 14.52 个百分点，可用 LUT 从 507 增至 3,528。最终实现包含 768 个分布式 RAM LUT 和 4 个移位寄存器 LUT。DSP 数量变化为综合映射结果，本次未专门修改乘法逻辑。

全部已约束建立、保持和脉宽检查通过；WNS 未达到前期预估的 +0.150 ns，较原版建立时间余量缩小，因此作为待上板验收的候选版本，不据此宣称时序改善。四组总线偏斜检查均通过，最小余量 +6.371 ns；19,868 个可布线网络全部布通，布线错误为 0。实现 DRC 有 56 项 Warning，无 Error，不宣称告警清零。

综合后、实现后均通过 `LUTRAM_PIN_CHECK_PASS 768`。主要证据位于 `Tetris.runs/lutram_final/`：`utilization_routed.rpt`、`timing_routed.rpt`、`route_status.rpt`、`lutram_pins_synth.rpt` 和 `lutram_pins_routed.rpt`；DRC 与总线偏斜报告位于其 `Tetris_lutram.runs/impl_1/` 子目录。
