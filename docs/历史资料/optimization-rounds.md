# LUTRAM 基线后逐轮优化

基线提交：`0a9b368`。器件：`xc7a35tfgg484-2`。工具：Vivado 2018.3。完成日期：2026-10-24。

基线完整实现为 17,272 LUT、6,261 个寄存器、15.5 BRAM、2 DSP，WNS +0.117 ns，WHS +0.097 ns。
按重复逻辑、组合路径、存储资源的顺序验证，最终保留颜色/归属 LUTRAM 与智能提示读口合并两项改动。完整实现为 **11,525 LUT、4,237 个寄存器**，相对基线再省 **5,747 LUT（33.27%）和 2,024 个寄存器（32.33%）**。本轮未修改 HDMI、网络发送模块和约束文件，原有两份根目录比特流保留。硬件上板尚未验收。

## 验证口径

- `sim/optimization/run.ps1` 从 Git 读取不可变的旧版 Playfield，使用工程真实形状及旋转偏移 ROM，比较镜像、碰撞、渲染与行写事务。
- 测试覆盖 3,000 组随机双人位置、类型和旋转，128 组同时或错开锁定，以及连续消行，共 74,497 次检查。
- `tools/screen_playfield.tcl` 使用相同综合指令做模块级初筛。该结果不与全工程实现值直接相减，也不作为合入证据。
- 候选采用 `tools/check_lutram.tcl` 完整综合、布局布线、生成比特流并核对所有场地 RAM 连接；各轮使用独立输出目录。
- 只有全量仿真通过、实际资源或时序有收益且不突破时序门槛的候选才能保留。

## 实现要点

- 元数据采用 24 个列 bank，每列 32×4 位，分别保存方块类型与归属；显示和搬移使用两份异步读 RAM，共 192 个 RAM32X1D 位实例。显示流水级数不变。
- 智能提示在不同状态共用棋盘行读口和高度表读口，高度表改为分布式 RAM。每轮搜索在使用前写满 20 列，因此无需数组复位。
- 智能提示继续保留 480 位原子棋盘快照。调用者不会对每次行写重新发起搜索，直接改成多拍读取实时棋盘会改变快照语义。
- `sim/optimization/run_hint.ps1` 对照随机棋盘、全部七种类型、搜索中重启、双人切换、停止、复位，以及搜索期间实时棋盘变化，逐拍比较状态与提示输出。
- 元数据测试使用真实写时钟和显示读口；没有为仿真保留旧寄存器数组。综合网表及实现网表核对 LUTRAM 原语数量；RTL 与 UNISIM 测试核对写入、显示读和搬移读的行为。
- 模块初筛的黑盒 ROM 与全工程优化边界不同；第一、二轮已证明局部节省不保证整体节省，因此最终只采用完整实现数字。

最终 LUT 利用率由 83.04% 降至 55.41%，剩余 9,275 LUT。布线后 LUT as Memory 为 1,160，其中 Distributed RAM 1,156、SRL 4；这些已经包含在 11,525 总 LUT 内，不能再次扣除。BRAM 保持 8 个 RAMB36＋15 个 RAMB18（15.5 tile）；DSP 由 2 变为 0，这是全工程综合映射结果，本轮未专门重写乘法。

## 最终复验与边界

- 场地新旧对照 74,497 项通过。
- 画面完整三模式扫描连同颜色/文字函数共 2,789,376 项通过，快速入口 24,576 项通过。逐像素检查的是优先级选择，存储行为由专项测试验证。
- 智能提示逐拍对照 1,399,517 项通过，覆盖随机棋盘、全部七种类型、搜索中重启、双人切换、停止、复位和搜索期间实时棋盘变化。
- 元数据 RTL 与 UNISIM 两模型各 29,768 项通过，另用 UNISIM 运行双人画面与消行存储联合回归。
- 原十套回归、优化单独入口均通过；修复脚本环境隔离后的十一套总入口 `sim/run_all.bat` 全部通过，退出码 0。
- 原场地 768 个 RAM 位在综合及实现网表中严格核对独立读地址及公共写地址、数据、使能和时钟连接。元数据检查器核对 192 个实例的数量、名称及 96 显示/96 搬移分类；元数据管脚未逐根核对，其事务行为由 RTL/UNISIM 测试验证。
- 14,217 条可布线网络全部布通，布线错误 0。实现 DRC 为 0 Error、47 Warning，并非告警清零。
- 已约束路径的建立、保持及脉宽检查均通过；四组总线偏斜通过，最小余量 +6.351 ns。WHS 较基线下降但仍为正。报告仍列出未约束端点、缺少输入/输出延迟等既有覆盖缺口，不能将此解释为所有路径均完成约束验证。

总入口此前在原十套通过后，优化首个工具启动失败，尚未执行断言；反复加载 `settings64.bat` 的环境污染可复现。`sim/run_all.bat` 现为每个子测试启动独立 `cmd /d /c`。另补全优化入口的存储子测试、默认候选路径与绝对工作目录。
