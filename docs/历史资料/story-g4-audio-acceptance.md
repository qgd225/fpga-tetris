# G4 代表性语音验证记录

2026-10-25。M1 已发布于 `0b937eb`，用户已反馈视觉上板无问题；本页是后续音频验证，不继承 M1 的听感通过资格。

## 当前范围

- 新增三拍 IMA ADPCM 解码器、单句 ROM/播放器、实际播放器驱动的 COMMS、带限幅的混音。
- 现阶段只验证开场 `YOU CAME.`，没有装入其余六句、通信事件优先队列或 HDMI 阶段配乐；不声称 M2 完成。
- 第一份干净样音为既有 Microsoft Zira Desktop 离线素材，6,748 个 8k 样本，0.8435 秒。现有单元测试已逐样本与 Python 3.11 标准库参考比对。
- 弱信号离线候选保留全部原采样，在两词之间增加 160 ms 停顿和轻低通底噪；8,028 样本、1.0035 秒、4,014 字节，未超过单块 8,192 个四位样本容量。已接入并通过播放器与 17 套回归，完整布线已通过，显示器听感未验收。
- 所有播放/解码留在像素时钟域；48k 使能每六次推进一个语音样本。暂停保持序号并作约 2.7 ms 音量包络静音，恢复续播；重开取消旧句与在途解码。
- 字幕框位于计划指定的右上 `[800,1248) × [24,120)`，复用共享字库；只随播放器实际 busy 显示，暂停/回菜单/结束隐藏，没有额外无声尾留。
- 语音期间普通 HDMI 操作音减半，紧急告警不减；混音接口预留 BGM 四分之一增益，但阶段配乐尚未接入。最终混音限制在 ±1,024。原蜂鸣器音乐在短语播放时暂时静音，后续第 4 轮统一替换为 HDMI。

## 输出边界收敛

首版弱信号候选时序非负但保持余量仅 +0.048 ns，按 T1 保持为黄色，不替换发布文件。最差路径为新增混音寄存器直接连接音频 FIFO。新候选使用上升沿计算寄存、下降沿送出数据；FIFO 仍使用原上升沿，不改厂商模块或时钟约束。新增两个采样边界断言，播放器 145,701 项通过，完整实现已通过；之后把暂停/重开/取消测试移至实际发声段加强，播放器 199,434 项通过。
