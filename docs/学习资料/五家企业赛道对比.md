## 二、AMD（赛灵思）赛道

分 4 个子赛道，工具链与 Xilinx 教程完全一致（Vivado / Vitis）。

**3.1 命题式基础赛道**（限大一至大三）

- 核心是**基于 Vitis HLS 的加速器内核设计**（推荐 AMD HLS 2024.2），二选一任务：信号处理任务 / 神经网络加速器设计任务。
- 明确要求用 LLM 辅助优化，DeepSeek、Qwen 等公开大模型均可，需提交**提示词与模型回答的交互记录**。
- 板卡限制：PYNQ-Z2。
- 优化目标：减少 BRAM、降低 II 提高吞吐、提高性能/资源比。
- 赛程：**10 月 18 日发题，11 月 1 日提交（两周）**，11 月 29 日现场决赛。
- 权重：功能正确性 30%、性能与资源优化 30%、LLM 辅助优化 20%、可复现工程与报告 20%。

**3.2 国际赛道（FPT 会议）**

- 面向 L5 无人驾驶与大模型推理加速，两个赛题：SLAM 算法 FPGA 加速、大模型激活函数 FPGA 加速（支持 bf16）。
- 平台：AMD KV260。
- 提交**英文论文**（IEEE 双栏、正文 ≤4 页）+ 可复现工程 + 5 分钟演示视频；决赛需英文 PPT 与实物。
- 权重：性能与技术创新性 40%、答辩演示 40%、论文 20%。

**3.3 自主选题—初级赛道**（限大一至大三）

- 可自由选择 **AMD FPGA / ZYNQ 系列器件**。
- 重点考察逻辑、状态机、时序、接口等**基本 FPGA 设计能力**；对 ARM 上的软件工作**不作为主要考核指标**。
- 需提交可复现工程，进决赛需在 GitHub/Gitee 开源；报告中必须包含 LLM 辅助优化内容。
- 权重：功能正确性 20%、性能与资源优化 20%、作品创新性 20%、LLM 辅助优化 20%、可复现工程与报告 20%。

**3.4 自主选题—高级赛道**（大四及硕博）

- 可用 AMD 的 FPGA、ZYNQ 和 **Versal** 器件，**无逻辑资源限制、无学历限制**，鼓励软硬件协同。

**板卡**：本次竞赛**无板卡租赁**，报名结束后提供有限数量的远程板卡（PYNQ-Z2 及 KV260）。

**技术支持**：AMD 中文技术论坛（forums.xilinx.com/cn）、交流 QQ 群 1022632722、Gitee 仓库 `gitee.com/Vickyiii/fpgachina25-amd`、云文档 `docs.qq.com/doc/DRlNzWnJua25MYWFL`、邮箱 fpgacamp.cn@outlook.com。

## 三、紫光同创（Pango）

**技术平台**

| 板卡 | 主控 FPGA | 关键资源 |
| --- | --- | --- |
| RK3568 MES2L50H | PG2L50H-61FBG484（Logos2, 28nm）+ 瑞芯微 RK3568J 四核 ARM | DDR3 16bit / 1066Mbps；4 路 HSST 6.6Gbps；2 路光纤、FMC、40pin、HDMI、千兆网 |
| 盘古 676（MES2L676） | PG2L100H-61BG676 或 PG2L200H-61FBG676 | DDR3 32bit 1066Mbps（34.1Gbps）；8 路 HSSTLP 6.6Gbps；2 路光纤、SMA、PCIe Gen2×4、HDMI 收发、千兆网、FMC LPC |
| 盘古 50（MES50HP） | PGL50H-61FBG484（Logos, 40nm） | DDR3 32bit 800Mbps；4 路 HSST 6.375Gb/s；HDMI 收发、光纤、PCIe、千兆网、40pin |
| PGX-NANO | PG2L50H-61MBG324（Logos2, 28nm, 50k 逻辑） | 2MB SRAM、MS9708 8bit DAC、ESP32（WiFi/蓝牙）、CP2102 串口、40pin 扩展 |

**选题**

1. **仪器仪表——FPGA 智能信号分析与测试系统**：ADC（≥8 位、500kSPS）采集 → 实时 FFT（≥1024 点，**原厂提供 IP Core**）→ 频谱显示（OLED/LCD/HDMI）；测量幅值、频率、占空比、THD。扩展：双通道同步采集与相位差、自动化测试；创新：微弱信号检测、AI 辅助诊断、蓝牙/WiFi 远程控制。分值：基础 40 + 扩展 30 + 创新 20 + 文档 10。
2. **智能制造——缺陷检测与空间定位**：工业相机采集 + 灰度化/中值滤波/边缘增强，模板匹配、阈值分割、形态学分析做缺陷识别；多传感器融合定位（X/Y/Z + 姿态角）；触摸屏交互、声光报警、GPIO 联动机械臂。分值：缺陷检测 40 + 空间定位 30 + 交互控制 20 + 性能优化 10。
3. **视频图像处理——软硬协同机器视觉**（推荐 RK3568 MES2L50H）：OV5640 采集（≥640×480、≥10fps）→ FPGA 预处理（灰度化、滤波）→ FPGA 或 ARM 做目标识别（传统算法或 MobileNet/YOLO-Nano 等轻量模型）→ HDMI 显示与交互。分值：基础系统 10 + 提升功能 70 + 场景创新 10 + 文档 10。
4. **自主命题**：基于紫光同创推荐板卡，从工业、通信、音视频图像三个领域中选一个方向；示例：移植老式游戏机、工业以太网 + FOC 电机控制、CPRI/JESD204B/NVMe 等协议实现。

**板卡**：企业提供 200 套盘古 50 / 盘古 676 借用，另提供 10 套 RK3568 MES2L50H 给第二、三类赛题；按报名队伍简介与解题思路综合评判借用。也可到淘宝店 `shop372525434.taobao.com` 以参赛折扣价购买，或自制/购买第三方紫光同创 Logos 系列板卡。

**支持**：B 站 `space.bilibili.com/507416742`；技术支持 QQ 群（OCR 不清，形如 10336?98）。

**就业政策**：全国一等奖及以上队伍核心成员可获 FPGA 开发岗 HR 面试直通卡（免笔试与技术面）；二、三等奖可获面试直通卡（免笔试）。

**选题**

1. **全景会议相机**：多摄像头（双摄 180° 超广角或多摄）同步采集，标定后拼接到球面/等距柱状投影，拼缝尽量小；按键控制视角旋转，HDMI 实时显示。扩展：USB/网口输出做全景 UVC/网络摄像头、麦克风阵列实现"虚拟云台"跟随说话人、视角缩放与小行星特效。
2. **无线通信系统设计（SDR）**：以高云 FPGA 为通信算法主芯片，自建信源编解码、调制解调、信道编解码、同步等，做成完整无线通信系统并自发自收；考察传输速率、占用带宽、FPGA 资源、误码率、传输距离与时延。频段：389–510MHz / 779–1020MHz / 2400–2483.5MHz。扩展：PC 端用 MATLAB/LabVIEW 构图、双平台互收、与真实通信系统（蓝牙、FM 等）互通。
3. **多功能协议调试器**：USB 转 SPI/I2C/UART/多路 PWM；数字信号频率/占空比/高低电平时间测量；驱动高速 ADC（并口或 LVDS，≥10Msps）采集存储传输；驱动高速 DAC（≥10Msps）输出 ≥5 种波形。扩展：USB HS/以太网、协议解析软件、时域与频谱显示、手绘波形、多模式（buffer/流）。
4. **开放型题目**：不限板卡型号，但**须体现高云 FPGA 主体地位，不使用 MCU**；鼓励创新性与工程完整性。

**板卡**：免费申请，**报名时须同时勾选申请**，每队仅限一块，企业按项目评审后抽取寄送，**完赛后寄回**（寄回地址：广州市黄埔区科学大道 235 号 601 房，杨晓玲 18718256030）。也可用第三方以高云芯片为核心的开发板。

| VF-Ti60F225 | Ti60F225B（16nm 钛金系列） | 60K 逻辑单元、160 DSP、集成 DDR3/MIPI 软核 IP、DDR3 4Gbit（K4B4G1646E）；8 LED、2 按键、HDMI 1.4、LVDS LCD（1024×600）、DVP 相机接口、MIPI RX+TX（CSI/DSI 1.5Gbps，需转接板） |

**开发软件**：**Efinity 2024.2**（官方提供资料下载）。

**选题**

1. **2mm 内窥图像开发**（VF-Ti60F225 + 2mm 1280×960 A2020 内窥模组，原厂赠送模组）：实现 720P60 实时显示 + 内窥图像处理（AE、AWB、消光、降噪、延时等指标）+ 更多内窥算法优化。板卡 1500 元（8 折），7 寸 LVDS 屏 300 元。
2. **畸变校正算法设计**（VF-Ti60F225 或 VF-T35F324 + 720P DVP 相机 SC1336 + 广角/鱼眼镜头）：FPGA 实时 720P60 畸变矫正并在 HDMI 显示，挑战 1080P60 加分，可按键切换矫正前后。套件 1088（T35）/ 1660（Ti60）元。
3. **多脸识别加速系统**（同上板卡 + 720P 相机）：实时多目标人脸检测识别，考察并发识别数量、速率与准确度；**充分利用 RISC-V 与 FPGA 硬件加速者可加分**。
4. **T20 FPGA ADC UI 开发**（VF-T20F256，仅 20K LE + 外部 ADC 模块 + 800×480 RGB LCD 触摸屏）：基础信号采集之上，重点考**FPGA 上的 UI 开发**与逻辑设计硬实力、T20 资源利用率；搭配 RISC-V 做效果者重点关注。板卡 398 元、ADC 模块 300 元、屏 168 元。
5. **参赛队自主命题**：任意搭载易灵思芯片的开发板，方向不限。参考方向：多路图像拼接（≥2 路输入、任意分辨率缩放 64×64~1080p、画布透明度、按键/UART 调节）、JPEG 压缩 + 网口传输（采集一帧 → FPGA JPEG 压缩 → 网口上传 PC）、TDC 时间数字转换（脉冲宽度测量 + 温度补偿 + 精度证明）。

**板卡**：免费借用（赛后归还，需官网报名后凭队伍编号申请进技术群，填写"板卡借用申请表"，审核后寄送）；也可通过第三方淘宝渠道 8 折购买。

## 六、给"用 Vivado / Xilinx 教程入门"的人的迁移成本排序

| 排序 | 企业 | 迁移成本 | 原因 |
| --- | --- | --- | --- |
| 1 | AMD | 最低 | 就是 Vivado / Vitis 生态；但命题赛道要用 Vitis HLS（C/C++ 写硬件），且无板卡租赁，只能申请远程板卡或自购 |
| 2 | 高云 / 易灵思 | 中 | 换 EDA（Gowin EDA / Efinity），但板卡好拿、有官方教学资源；高云还有小梅哥渠道 |
| 3 | 紫光同创 / 安路 | 中偏上 | 换 EDA（PDS / TD），板卡资源与例程也够，但要重新学工具、约束与 IP |

Verilog RTL 代码、状态机、时序、波形调试思路这些**换到任何一家都能直接复用**；需要重做的永远是：工程文件、管脚与时序约束、厂商 IP（PLL、BRAM、DDR 控制器、收发器）、下载与在线调试流程。
