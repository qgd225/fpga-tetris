## 二、四个推荐平台的硬件规格

### 平台 1：EG4S20 开发板 + ES8388 音频采样模块

- **核心 FPGA**：EG4S20BG256，256 管脚，19600 个 LUTs，1 Mbits 嵌入式块存储器（BRAM），内置 2M×32bits SDR SDRAM，内置 12 位 ADC。
- **外围设备**：晶振、LED、数码管、蜂鸣器、按键开关、拨动开关、UART 转 USB 接口、DAC 电路等。
- **通用 IO**：上 42 + 下 37 + 左 36 + 右 22 = 共 **137 个通用 IO**，另有若干 GND / Power 通道；顶边与底边各标注 **6 对 LVDS 差分对**。
- **板载调试**：板载 USB 转 JTAG 调试电路 + UART2USB 电路，**一根 USB 线即可完成供电、调试和串口通信**。
- **音频部分**：提供 1 个 **ES8388 音频 codec 模块及配套麦克风**，并提供示例驱动代码。该模块非必须，可换用其他**不带额外处理器**的音频采样与回放模块。
- **板卡资料**：百度网盘文件 `EG4S20`，链接 `https://pan.baidu.com/s/1C02hvFlxa07VNtrzFAKGoq?pwd=529c`；更多信息见语雀 `https://www.yuque.com/yingmuketang/01/bus6r2z91g8fywwi`。

### 平台 2：HX4S20C 开发板

- **FPGA**：安路 EG4 系列 EG4S20BG256，LUTs 19600（赛题简介中写作 19600 个 DFF + 19600 个 LUT）。
- **调试下载**：板载 USB 下载器。**供电**：USB 口 5V 供电，板载 5V / 3.3V / 2.5V / 1.2V 电源系统。
- **人机交互**：4 组输入按键、1 组配置按键、4 组拨码开关、1 组控制蜂鸣器开关、1 组切换数码管与双色 LED 开关。
- **显示**：4 组 LED 发光管、1 组电源显示 LED、1 组配置信号显示 LED、8 组数码管、8 组双色共 16 个 LED。
- **通信接口**：USB 转 UART、千兆以太网口、蜂鸣器。
- **存储器**：掉电配置 QSPI Flash 16MB、SPI Flash 64MB、TF 卡槽。
- **视频接口**：双 HDMI 接口（可作视频输出）、12 位 VGA 接口。
- **用户外扩 GPIO**：2 组 2×20（DC3）共 72 组扩展 IO，可扩展 LCD、ADC、DAC、摄像头模块、电机、HDMI 输入模块、交通灯、点阵、键盘、语音处理等。
- **时钟源**：50M 有源时钟。
- **板卡资料**：网盘文件 `HX4S20_contest`，链接 `https://pan.baidu.com/s/11YsOv2f9150RnNZccm9Crg?pwd=je6f`，提取码 `je6f`。

### 平台 3：MLK-H10-PHIA180 开发板

- **FPGA**：PHIA180SFG676（凤凰系列）。
- **存储（核心板）**：DDR3 2 片共 1GB，数据带宽 1600Mbps×32bit；焊接 256Mbit Flash，型号 GD25Q256DYIGR（固化程序、存放数据）。
- **以太网**：底板集成 2 路以太网接口，支持 10 / 100 / 1000 Mbit/s。
- **其它接口**：1 路 TYPE-C/UART；1 路 FEP 扩展接口（36 GPIO / 18 对差分）；1 路 TF 卡；1 路 CAN + 1 路 RS485；I2C EEPROM（24C02）；实时时钟 RTC（1 路）。
- **显示与扩展**：HDMI 输出可达 1080P@60Hz；FMC（HPC）扩展接口 4 对 GT，最大 12.5Gbps；PCIE 3.0×4，8Gbps×4 Lane；MIPI 1 路 2×4LANE@2.5Gbps；底板 4 个 IO / 8 颗 LED。
- **时钟 / 电路**：100M 差分时钟 + 25M 单端时钟×2（两路以太网使用）；核心板 14 层、底板 6 层；集成电源管理，内核 0.95V@30A。
- **供电与结构**：DC-12V@3A；100mm×190mm（核心板 50mm×68mm）；连接器 DF40C-100DS×4；最大功耗 13W；被动散热（散热片 50×11×68mm）。
- **板卡资料**：`https://pan.baidu.com/s/1Vlw15kqsoBGOzLfDSfZEiA?pwd=su9f`，提取码 `su9f`。

### 平台 4：MLK-F3P-DR1M90G 开发板（飞龙 DR1 异构 SOC）

- **主芯片**：DR1M90GEG400。
- **处理器**：双核 Cortex-A35，最高主频 1GHz；处理器扩展支持 NEON 与单/双精度浮点；ARM 通用定时器 8 个（其中 4 个专用于可编程逻辑）。
- **可编程逻辑资源**：LUTs / DFFs / DSP / PLL = 94464 / 104960 / 240 / 8。
- **加速与媒体**：NPU 512×MAC、256KB SRAM、0.4T 算力，支持定制算子；JPU 支持 JPEG 硬编解码。
- **内存与存储**：PS DDR 为 DDR3L 1GB（两片）1066MHz×32bit；QSPI Flash 128Mbit（4bit×125Mbps）；另有 SD 卡接口与预留卡接口（不焊接 eMMC 时可用）。
- **板载外设**：USB2.0 HOST / OTG（共 2 路 USB2.0）、PL 千兆以太网、PS 千兆以太网、HDMI 输出（最大 1080@60fps）、JTAG UART、音频模块（1 路输入 1 路输出）、按键 4、LED 5、EEPROM 24LC02、RTC DS1337、CAN 1 路、RS485 1 路、1 路 TYPE-C。
- **无线与扩展**：WIFI 模块 + 天线、4G 模块；FEP 高速扩展接口 48 GPIO / 24 对差分。
- **时钟**：PS 晶振 33.3333MHz（核心模块上）、PL 晶振 100MHz（底板上）。
- **供电**：5V@3A（核心模块）、12V@3A（功能底板）；内核 0.95V 电源最大输出 8A。
- **板卡资料**：`https://pan.baidu.com/s/19KOTCvzRlZPKf3m5EkwQqw?pwd=dp7y`，提取码 `dp7y`。

## 三、各选题的硬件要求

### 选题一：FPGA 语音信号处理算法实现与应用

- 平台：EG4S20 开发板 + 音频采样模块。
- 在基于安路 EG4S 系列芯片的板卡上**自行设计或采用成品音频外围电路**，实现语音相关算法并展示应用场景。
- 算法方向（不限）：声源定位、语音识别、语音去噪、录音降噪/增强、音频编解码、音效增强、盲源分离、情感识别、语音合成、声纹加密/模拟，或多个算法有机结合。
- **硬性限制**：所用麦克风拾音模块和音频输出模块上**不得带有额外处理器**（无论用作胶合逻辑还是算法预处理）；作品展示的所有算法必须**在 FPGA 中自主编程实现**。
- 算法复杂时可用**多块同款 FPGA 板卡组成主从结构**，划分主/从节点任务，通过自定义链路实现板间通信。

### 选题二：基于安路 FPGA 的以太网数据传输系统

- 平台：**必须使用 HX4S20C 开发板**（主芯片 EG4S20BG256）。
- 硬件涉及：千兆以太网口、USB 转 UART、TF 卡槽 / SPI Flash（存图）、双 HDMI 与 12 位 VGA（显示）、外接摄像头模块或 HDMI 输入模块（视频输入）、72 组外扩 IO。
- 基础要求（4 条）：以太网接收 PC 命令控制 LED / 数码管；接收 PC 图片并在 VGA / HDMI / LCD 显示；把板上图片（TF 卡或 SPI Flash）经以太网发回 PC 显示；用摄像头模块或 HDMI 输入模块做视频输入经以太网传到 PC 显示。
- 扩展要求（4 条）：两块开发板以太网互联、用 FPGA 发送端替代 PC；FPGA 端做实时图像处理、PC 端显示结果；对采集图像做目标检测识别并传输到另一终端显示；其他以太网图像传输创新与低延迟/实时性/高可靠性/低逻辑资源改进。

### 选题三：基于安路 FPGA 实时图像信号传输系统

- 硬件：**推荐**安路凤凰系列 PHIA90 / PHIA180 芯片的 FPGA 开发板（含 MLK-H10-PHIA180），**不限于**推荐开发板。
- 该选题**需要一定 FPGA 开发基础**，要充分利用 FPGA 的资源与接口（高速串行 IO、PCIE 硬核、DDR3/DDR4 存储接口等）。
- 应用领域可覆盖：机器视觉、工业相机、数据通信、医疗图像、广播图像；技术要点覆盖 FPGA 图像算法、数据通信、信号采集与处理。
- 实现形式：可做其中部分子系统方案，也可做多个子系统整合的大系统方案。

### 选题四：基于安路飞龙系列 SOC 的智能人机交互系统

- 硬件：**要求使用安路科技飞龙系列 DR1 系列开发板**（含 MLK-F3P-DR1M90G），**不限于**推荐开发板。
- 属于 FPGA+ARM 异构 SOC 开发，难度高于普通 SOC 或 FPGA，既需要 FPGA 开发能力，也要掌握 ARM 嵌入式开发能力，并完成应用场景部署。
- 应用领域可覆盖：机器人、机器视觉、医疗图像、仪器设备、电力、物联网；技术要点覆盖异构计算、人机交互、FPGA 图像算法、信号处理和显示。

### 选题五：自主命题

- **不限板卡型号**：可基于安路推荐板卡，也可自制板卡。
- 鼓励创新性与工程完整性的作品，按创新性、趣味性、实用性综合评判。

## 四、各选题的软件与资料要求

| 选题 | 需要的软件 / 开发工具 | 随板提供的资料与例程 |
| --- | --- | --- |
| 选题一 | 安路专用 EDA 软件 + FPGA 内自主实现的算法代码（音频外围电路的示例驱动代码随板提供） | ES8388 音频 codec 模块及配套麦克风、示例驱动代码；EG4S20 板卡网盘资料 |
| 选题二 | 需要在 FPGA 内自建**物理层 PHY → 数据链路层 MAC → TCP/IP 协议栈 → 应用协议**的完整软硬件架构，速率 100/1000Mbps；PC 端上位机软件可用组委会提供的，也可自制 | 开发板使用手册、原理图、基础实验与接口例程、相关调试软件及以太网协议；赛题参考例程 `lab_ex1 ~ lab_ex4`（网口调试助手发指令控制 LED；接收 PC 图片经 HDMI 显示；TF 卡图片读入 SDRAM 经 VGA 显示；TF 卡图片经以太网回传 PC 保存显示） |
| 选题三 | 安路专用 EDA 软件；FPGA 图像算法与高速接口开发 | 参考方案：安路 FPGA 图像处理方案、AXI-FDMA DDR 缓存方案、UDP 以太网通信方案、GTX 高速串行通信（光口通信）方案 |
| 选题四 | FPGA 侧用安路专用 EDA 软件；ARM 侧用 DR1 SOC SDK（裸机 / Linux 两套路线），需掌握 Linux 驱动与应用开发 | 参考方案：FPGA 图像处理方案篇、AXI-FDMA DDR 缓存方案、UDP 以太网通信方案，加 DR1 SOC SDK 裸机基础入门 / 裸机高级应用 / Linux 基础入门 / Linux 驱动开发 / Linux 应用篇 |
| 选题五 | 不限（自制平台自行安排） | 自制平台可加竞赛交流群获取支持 |

## 五、开发板获取途径（硬件获取方式）

1. **提前获取板卡**：在推荐平台网店**全额支付板卡费用作为平台押金**，并告知参赛身份，便于后期退款（超出平台赠送限制套数需自行购买）。
2. **退还押金条件**：初赛成功提交作品、被组委会判定为有效参赛作品后，提前获取开发板的队伍可填写板卡申请表退还押金；**未提交有效参赛作品不退还押金**（非有效作品即滥竽充数、提交不完整等）。
3. **未交押金获取板卡**：可在报名结束后审核通过，填写板卡申请表，工作人员按限制赠送套数筛选，联系取得借用资格的队伍寄送板卡。
4. **其它规则**：提交完整作品则免费获得平台（不超过赠送套数限制）；**每支队伍仅能免费申请一种平台**；**子卡需自行购买，不可免费申请、后期也不退款**；优势是 8 月即可拿到开发板开始设计。
