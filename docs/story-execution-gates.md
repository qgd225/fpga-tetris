| 门禁 | 通过需要的证据 | 未通过时怎样处理 |
| --- | --- | --- |
| G0：任务不回退 | 保持 R1 单人 32/双人 40 行、四段八档、批次旧倍率、冻结与安全写事务；337 项任务专项、元数据 RTL/UNISIM 及完整 14 套回归通过 | 修复本轮引入的问题，不重写一套任务逻辑；保留上一发布 bit |
| G1：时序先收敛 | 同策略全工程布线，WNS/WHS 均 ≥+0.050 ns，TNS/THS=0；无新增未知时钟、内部未约束路径或锁存器；首末像素与 TMDS 反解相位正确 | 先切短坐标→psel 路径、统一流水；不加装饰、不放宽时钟/伪 false path。R1 +0.023 ns 为历史已知例外，不继承 |
| G2：布局冻结 | mapper 全帧软件参考相符；24 格距 mapper 净增预算 ≤120 LUT；最小 UI 布线过 G1；15.6 英寸实屏能辨七类块、双方归属、NEXT/HOLD | 先简化选择和加级，仍不行则 32 格距重排；16 仅实屏证明可读才考虑，不盲目缩小 |
| G3：字体回收 | 全字形、固定文本、数字与边界扫描通过；旧六份 ROM 实例全部消失，7.5 tile 旧字库被替换；新字体 ≤1 tile，净回收 ≥6.5；菜单/结果/准备目标卡可读 | 字库未达标先修复或按真实容量重算；不得提前记 −7 tile、冻结全套语音 |
| G4：代表性音频 | 字库门禁后验证约 2 秒弱开局语音；软件/RTL 逐样本一致，48k/8k 序号不丢不重；忙闲/暂停/重开/抢占正确；显示器听得清，COMMS 只在有声时显示 | 先修素材、解码和包络，必要时缩句/删底噪；占位音不算配音完成 |
| G5：全套语音容量 | 资产清单有每句起址、初值、样本数、总时长；连续打包 `ceil(N_total/8192)`，主 ROM 网表映射相符；按真实 B_without_voice + B_full_voice 核算 | 剪无效静音/重复句；不压语速、不把每句猜测时长或未回收字体算成收益 |
| G6：音画与玩法 | 四阶段无标题截图仍可分辨；真实危险不抹掉修复；成功静音演出约 1.2 秒后才播回应与结算；暂停/重开取消旧表现；八档双人试玩通过 | 减可选动画和背景细节，保证可读与操作；物理锁定等玩法调整另列变更 |
| G7：整机发布 | LUT ≤14,015、BRAM ≤28 tile；目标 LUT ≤13,615、BRAM ≤25；新增寄存器目标 ≤1,000、锁存器 0，DSP 默认 0；G0/G1/音视频协议/调色板/768+192 RAM 位连接通过；唯一 bit 与源码匹配 | 不覆盖发布 bit，记录失败与削减；完整通过后本地 main 中文提交，是否上板分别说明 |

下一视觉组合轮另设相对 R1 的净增预算 ≤1,000 LUT（总量 ≤12,922）。超过子预算先说明调配和收益，整机上限不变。只做模块综合、只有 LUT 下降或仅画面截图，均不足以通过完整轮次验收。

当前基点：`81e75a1`，11,922 LUT、4,525 寄存器、15.5 BRAM、0 DSP；14 套回归通过，尚未上板。报告见[第一轮构建摘要](<D:/vivado_project/Tetris/docs/reports/story_r1/build-summary.txt>)。

削减顺序：额外装饰/多处闪烁 → 行星 → 多余声部/连续底噪 → 重复告警/次要语句 → 可选手套退出/动画幅度。保留清晰方块、四阶段结构、通关闭环与关键结果回应。
