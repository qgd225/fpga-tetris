# 新UI A2：公共基础层接入

日期：2026-10-28。依据[新UI计划书](../../计划书/新UI计划书.md)，承接用户“继续”。本轮完成场地、原方块／残骸、NEXT/HOLD共享材质与公共文本后端的实际接入，尚未完成整机新UI。没有删除装饰或动态，没有提交、推送或生成bit。

## 已接入的内容

- `ui_basic_layer`进入实际`reference_ui_renderer`输出路径，负责场地格线、原始22×22块面、薄X残骸、双人角标、落点轮廓、单人智能落点、NEXT/HOLD方块与HOLD状态边框、消行反馈。
- P1 NEXT、P2 NEXT、共享HOLD共用一套同步材质图集；P2保留闯关／无尽两种交界材质变体，避免将闯关导管／沟道残影带入无尽。四种逻辑变体共443个8×8图块、254个本地图集颜色，容量251546bit。
- 本地图集使用8位索引，色表同时保存24位RGB和11位全局色号。这是1437色总表的局部子集，不是再次把整套UI压进256色；不改颜色、纹理位置或形状。
- 活跃的游玩、菜单／选关及对白文本改走公共5×7字库；字母、数字与符号同一条路径。文本坐标换成固定除数的栅格解码，未保留逐像素可变除法。
- 外部延迟保持不变：基础层／材质三拍，字体两拍；在参考渲染器第四拍统一优先级，story_ui再寄存一拍。坐标、有效标记与叠加顺序一起对齐。

原`phase_glyph`定义保留给既有字形资产生成器读取，当前像素着色不再调用它；没有两条字形链同时给当前界面上色。旧story_ui的终局等回退入口尚未更换，不能将本轮称为全状态字体与结算改造完成。

## 真实RTL对照

冻结A2改动前的渲染器作为独立RGB对照，使用相同输入夹具和同一套已审核的近色材质。最终HDL完成7张整图和9张局部状态帧，合计6,751,856像素，零RGB差异。七张整图和九张局部帧采用相同最终HDL；局部帧因仿真文件名覆盖而使用固定名称重新导出，并增加未知像素检查，整图不受这一测试台修改影响。不是与未经合色的原参考RGB零差异；原色误差仍沿用A1已记录的近色映射。

- 七整图：单／双人闯关、单／双人无尽、主菜单、单／双人选关。
- 九局部帧：对白、暂停、HOLD五状态、消行反馈、任务完成划线。
- 字库两种两拍流水组织均通过16384组字符／行／列组合比较，包含空白和无效区域。

## 独立综合与接口时序估计

器件`xc7a35tfgg484-2`，周期13.473ns，输入／输出采用max2.0ns、min0.2ns的相邻寄存器接口假设。未设错误false path，未降低时钟。以下为综合估计，尚未布局布线；接口假设不代替整机真实上下游路径。

`ui_basic_layer`已包含材质图集，`ui_text_raster`已包含公共字库，父子资源不能再次相加。独立图集保留全局色号输出，基础层暂未使用此输出；综合上下文裁剪和ROM打包可导致8.5／8 BRAM的差别。这里不是整机新增量，**尚不能确认新整机已留足800 LUT**。

补加接口约束后，曾发现火花算式和选字路径估计违例。已分别将火花种子／取模／命中判断分摊到原三拍内，以及在原两拍字体中先寄存字符再查字形；画面和对外延迟保持一致。最终基础层和文本栅格的估计WNS均非负。最终整机WNS／WHS／TNS／THS仍必须在A6完整布线时确认。

## 当前边界与下一步

本轮公共层和字库已接入，工程已登记相关HDL、头文件和初始化ROM。船况头、核心／导管、其余船壳、菜单底材等仍使用已审核的预览路径；正式初始化数据已与审核图使用的近色bank逐字节一致；五张整屏预览ROM尚未全部替换，整套UI还不能据此宣称满足器件容量。网口／PC的11位扩色、分包与解码也未接入，发布bit保持旧版。

下一阶段A3继续替换重点模块的材质与状态渲染，再推进公共色号输出、其余场景及整机资源闭合。资源不足时继续先外围装饰、后动态，不动P0功能和P1重点轮廓。用户未要求本轮削减外观，因此当前没有使用删减版画面冒充完整目标。

## 复现与来源

`python tools/run_new_ui_a2.py`生成共享图集、验证两种字体流水、局部综合并导出7＋9帧；`--prepare-only`仅准备输入。所有运行产物位于temporary/new_ui_a2，不打开或重置正式工程运行，不生成bit。既有A1入口已补齐新公共层依赖，供后续复现。

本轮只修改UI渲染、生成器、初始化数据、工程登记和文档。游戏核心文件相对基线46745c1无改动；正式bit SHA256仍为`851ba01534ee3aa60f0ba8c65514dbb7b1787050675f644cab1cadbaab5b7127`。源文件、图集、对照版本、延迟与帧指纹见[manifest.json](manifest.json)。出图后等待审核，不自动开始A3。
