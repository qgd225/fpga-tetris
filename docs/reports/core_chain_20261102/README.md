# 核心锁链清零解除修正

2026-11-02完成并发布。以前锁链随LOCKED电气状态结束而消失，第一关可能清掉底行就进入HALF并误解锁。现在机械锁链独立读取剩余残骸：只要非零，六圈完整保留；残骸清零才统一移除。LOCKED仍为暗芯与红警戒，HALF可在链后点亮已有进度允许的最多四段电芯，警戒带为琥珀色。没有改变记功、HALF阈值、段数上限或成功条件。

新增只读、按帧采样的残骸减少观察器。减少时触发18帧导管推进和柱内扫光：LOCKED红、HALF琥珀，清零后青白。反馈计时在暂停时冻结；选关、换船、重新开局不会误触发旧清骸事件。保持现有五拍像素输出、网络音视频和PC功能。新增观察器不回写游戏状态，也没有新增时钟或时序例外。
