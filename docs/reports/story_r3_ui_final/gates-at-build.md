# 故事化逐轮门禁清单

2026-10-25 二次修订。规格见[正式计划](<D:/vivado_project/Tetris/docs/CORE-07_故事感实施计划书.md>)；理由见[评审取舍](<D:/vivado_project/Tetris/docs/story-review-decisions-20261025.md>)。**本表是资源/时序验收限额的唯一规范来源**，正文和评审记录只引用编号；历史实测值、容量推导和结构估算不是额外限额。门禁尚未全部自动化。

## 唯一限额表

| 编号 | 数值与口径 |
| --- | --- |
| T1 | 完整通过目标：WNS、WHS 均 ≥+0.050 ns；约束硬底线：两者 ≥0 且 TNS/THS=0。按 G1 分级，不把余量目标当器件物理分界 |
| R1 | LUT 软目标总量 ≤13,615；绝对上限 ≤14,015 |
| R2 | 视觉累计净增预算 ≤900 LUT，相对任务轮 11,922，即总量 ≤12,822；覆盖 2A、2B、3 的 mapper/流水/字体/布局/核心/背景/表现控制，不含 2C 音频原型 |
| R3 | PCM、配乐、ADPCM、通信与混音合计净增预算 ≤750 LUT，相对同一任务轮；原型被完整语音替换时不重复计。通用开销只能归一组 |
| R4 | 24 格距 mapper 相对旧 mapper 净增预算 ≤120 LUT，包含在 R2 内，不额外相加 |
| R5 | BRAM 目标总量 ≤25 tile；绝对上限 ≤28 tile |
| R6 | 新字体 ≤1 tile，旧字体净回收 ≥6.5 tile；旧六份共 7.5 tile 必须全部消失。未达时先修复或重算容量，不沿用原语音假设 |
| U1 | UI轮相对音频版 9,360 LUT 净增目标 ≤900；BRAM相对 25 tile 净增 0；寄存器仍遵守R7、新增Latch 0、DSP 0 |
| R7 | 相对实施前 4,447 寄存器，新增目标 ≤1,000；新增锁存器 0，DSP 默认 0 |

预算闭合：`11,922+900+750=13,572`，软目标内剩 43 LUT 用于尚未归属的整合开销。该余量不是免费功能额度；变更组间分配先更新本表和账目。超过软目标但未到绝对上限也必须先削减/调配并说明收益，不自动放行。

## 逐轮检查

| 门禁 | 通过需要的证据 | 未通过时怎样处理 |
| --- | --- | --- |
| G0：任务不回退 | 保持 R1 单人 32/双人 40 行、四段八档、批次旧倍率与安全写事务；任务专项、元数据 RTL/UNISIM、完整回归通过（现 15 套，含 mapper 专项） | 修复本轮问题，保留上一发布 bit，不重写第二套任务逻辑 |
| G1：时序分级 | 同策略完整布线、T1；无新增未知时钟/内部未约束路径/锁存器；统一像素相位，首末像素与 TMDS 反解正确 | 绿色：达到目标，可叠下一图层；黄色：非负但低于目标，只可做资产、局部验证及不加视觉组合深度的候选，每次集成仍测整机，不能认定轮次通过或替换正式 bit；红色：任一 slack 为负或 TNS/THS 非零，回退失败候选 |
| G2：布局冻结 | mapper 全扫描软件参考相符、R4；最小 UI 达 G1 绿色；实屏按正文 5.3 的固定样本流程比较候选与旧布局 | 先简化路径/统一加级；仍黄色则停止加视觉层，做 32 格距重排对照；16 仅实屏证明可读才考虑 |
| G3：字体回收 | 全字符/固定文本/数字/边界扫描；旧六 ROM 消失且达 R6；菜单/结果/准备目标卡可读 | 修字体或按真实网表重算容量，不提前扣尚存 ROM，不冻结全套配音容量 |
| G4：代表性音频 | G3 后约 2 秒弱开局片段；软件/RTL 逐样本、48k/8k 序号、暂停/重开/抢占通过；显示器能懂，COMMS 只在有声时出现 | 改素材/解码/包络，噪声先减；占位音不算配音。此项不阻塞视觉里程碑 M1，但在装全套配音前必须完成 |
| G5：全套语音 | 真实资产清单、样本数、初值与连续打包容量；B_without_voice+B_full_voice 达 R5，整机音频增量达 R3 | 剪无用静音和重复句；不压语速、不提前扣旧字体；离线信号修复梯度须先通过可懂度试听 |
| G6：音画玩法 | 四阶段无标题仍可区分；只有核心一处开合动画；背景能流止于核心；失败不抹修复；成功先静音演出后回应；八档双人试玩 | 减装饰/可选动画，玩法参数另列变更；结果语域按 LINK LOST 与未完成修复统一 |
| G7：整机发布 | R1～R7、G0/G1 绿色、音视频协议、调色板及 768+192 RAM 位连接；唯一 bit 匹配源码；按当前里程碑检查所需门禁 | 候选不覆盖正式 bit，记录失败与削减。M1 不要求尚未开发的 G4/G5，但也不能自称全部故事功能完成；M2 全部检查 |

G1 收敛路径：最小 UI 先完成真实最差分支简化和必要流水重划；仍黄色就暂停 24 格距图层扩展，以同工程的 32 格距对照判断布局成本。32 达目标且可读则采用；仍未达则保留 R1 发布、记录真实限制，不能自动把门槛降到现有结果。路径报告记完整寄存器到寄存器起终点；不捏造各绘制图层的“独立 slack”。

当前实测基点 `81e75a1`：11,922 LUT、4,525 寄存器、15.5 BRAM、0 DSP；WNS +0.023、WHS +0.061 ns；14 套回归通过，尚未上板。它是历史已知黄色，不向新里程碑继承通过资格。[第一轮报告](<D:/vivado_project/Tetris/docs/reports/story_r1/build-summary.txt>)。

削减顺序：额外装饰/多处闪烁 → 行星 → 多余声部/连续底噪 → 重复告警/次要语句 → 可选手套退出/动画幅度。保留清晰方块、四阶段结构、通关闭环与关键回应。
