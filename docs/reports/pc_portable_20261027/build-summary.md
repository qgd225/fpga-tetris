# PC 便携程序与无板网口自测交付

日期：2026-10-27。已更新根目录 `TetrisPC.exe`，版本 `2026.10.27.3`；本次不提交 Git、不推送 GitHub。

## 修复与交付

- 发送源地址来自实际有线网卡与路由，不再按主机 IPv4 字符串排序；排除 VPN、虚拟网卡、无线网卡和断开接口。Realtek 品牌不能单独作为有线判断依据。
- 多块未配置 FPGA 网段的有线网卡需要用户选择，支持 `--interface` 明确指定；不自动猜第一块，也不将地址重复配置到已有冲突接口。
- 静态 ARP、路由修复按真实退出状态执行备用链；Windows PowerShell 5.1 下合法调用原生命令，并处理原生命令标准错误流，不能靠输出 OK 判断成功。
- 需要权限时，只请求系统 PowerShell 执行网络配置；显示程序不因自动配置重新以管理员权限启动。自测和 `--check-network` 不提权、不修改 IP／ARP／路由／防火墙。
- 接收与自测共用 pc_protocol.py，检查包头、行号、长度及调色板结构；端口占用明确报错。正常退出停止后台线程并尝试发送按键全释放；发送阶段成对启用和恢复定时分辨率。
- 日志存于用户可写的 `%LOCALAPPDATA%/TetrisPC/Logs/`，不要求对安装目录有写权限。报告路径缺少父目录时自动创建；非交互诊断失败只返回错误，不弹阻塞对话框。
- 新增 [network_selftest.py](../../../pc/network_selftest.py) 与 [网口自测.bat](../../../pc/网口自测.bat)。EXE 内置同一自测，可在没有系统 Python 的环境使用。
- 提供 TetrisPC.spec、requirements-build.txt 与 build_pc_exe.py；候选和构建中间产物直接输出 temporary。发布前核对 EXE 与源码，不继续交付旧色表程序。

## 自测方法

双击 `pc/网口自测.bat`：1 为本机回环，2 为监听外部 UDP，3 为向接收电脑发送模拟 FPGA 包。两台普通电脑可完成收发检查，不需要 FPGA；实际命令和 IP／端口说明见 [PC 使用说明](../../../pc/README.md)。

本机回环只证明软件收发与解析，不能证明物理网口、线缆或防火墙入站。发送成功也不代表对端接收。监听分别统计所有 UDP 与有效 Tetris 数据，显示来源；外部地址不能直接等同有线物理路径，用户须结合实际连接和所选地址核验。

## 自动验证结果

[source-test-results.json](source-test-results.json) 中 12 类源码检查通过：语法、有效／损坏协议包、多网卡和提权分支、隔离 PowerShell 备用修复、本机真实 UDP、端口独占、噪声不误判、独立进程收发、生产接收路径与 56 色表、无线接口排除、原生命令错误流、异常时恢复定时精度。网络配置命令由假函数替代，实际只执行无副作用的原生命令错误流测试，未修改本机网络配置。

便携 EXE 在仅放一个 EXE 的中文／空格目录中测试，从另一个工作目录启动；环境 PATH 只保留 Windows 系统目录，清除系统 Python、虚拟环境及 Tcl／Tk 路径。通过：

- 版本读取和本机 UDP 回环：8 个行包、1 个调色板包完整接收。
- 冻结程序内调用原生 Windows PowerShell，只读枚举网卡与路由成功。当前机器无可用已连接有线接口，connection.ready 为 false，不将枚举成功认作物理链路通过。
- 隐藏软件窗口检查：Tk 8.6.12、Pillow、pynput 键盘后端和当前 56 色表可用；未生成 RTL 画面或连接 FPGA。
- 两个独立 EXE 进程通过真实本地 UDP 发送／接收 5 个行包与 1 个调色板包；本机来源被明确标为外部入站未验证。
- 无数据、无效协议、端口占用及非法参数正确失败，未误报通过。
- 从打包归档读取 6 个程序模块，与当前源码编译结果逐模块对照一致，消除旧 EXE／新源码不同步问题。
- 正式 EXE 替换后再次读取版本、执行回环；两个批处理入口在无 Python PATH 条件下正常调用该 EXE，并正确转发参数。

第一轮隔离检查发现报告父目录不存在时出现阻塞错误窗口，已修复并在最终版本重新通过嵌套新目录报告测试；旧候选没有发布。最终证据见 [portable-exe-verification.json](portable-exe-verification.json)、[批处理检查](batch-entry-verification.json) 与 [构建输入](package-inputs.json)。
