# 新UI A1首轮：近色、同步材质ROM与公共字库

日期：2026-10-28。依据[新UI计划书](../../计划书/新UI计划书.md)。已完成本轮原型与测量，整机落地未完成，等待用户审核合色观感后接入下一阶段。本轮不提交、不推送、不生成bit。

## 本轮实现

- `ui_exact_tile_rom.v`：三拍同步8×8字典材质ROM，无减采样；对编码输入的RGB无损，支持非顺序坐标访问。
- `ui_font_5x7.v`：共享两拍5×7字库，不混用字母与数字字体，不在逐像素路径做可变除法；字形取自现行预览渲染器。
- 近色编译：保留原56色，共有53156种静态源颜色，试编到1437色，需11位色号。CIELAB D65 ΔE76阈值3，找不到近色就新增，不硬压到56或256色。原始参考图未改；当前阈值待本轮审核。

## 独立综合实测

目标器件`xc7a35tfgg484-2`，Vivado2018.3，13.473ns内部时钟约束。

| ui_a1_next_raw | 114 | 3 | 9 | 0 |

NEXT由9降至4.5 BRAM；核心壳体由4降至3.5 BRAM；字体89 LUT、0 BRAM。这些是独立原型，**不能相加当成新整机总量，不能宣称已留足800 LUT**。ROM读寄存器大多吸收进BRAM，FF栏只列可见片外寄存器。

时序报告仅为综合后的内部路径估计，ROM约+10.138ns、字库约+10.299ns；输入／输出接口未设整机延迟，没有经过布局布线。最终WNS／WHS及整机容量均未验收，不能复用旧版时序或据此发布新bit。

第一次Vivado加载库失败；本次进程的TEMP/TMP和用户路径变量原值异常。仅在本任务批处理子进程中设置合法路径后测量完成，未修改系统环境或安装文件。四个ROM报告与字库报告均已归档。

## 整机尚需解决的成本

在尚未实现硬件端局部变长色表的紧凑位数估算中，近色后的完整五bank共享图块仍需约3914608bit（16×16方案容量下限107 BRAM）；仅保留指定区域的8×8容量探针也约1827520bit、50 BRAM。它们不含端口碎片与解码器，且不是最优压缩不可能性的证明。旧发布版已占31/50 BRAM，不能直接接入全屏图块表。

后续路线是共享区域图集、局部低位索引、稀疏区域映射和旧UI回收，再做整机测量。必要时仍先裁外围装饰，再裁动态；本轮尚未实际删减任何装饰或动态，不偷用800 LUT预留，也不擅自降重点模块外形。

## 网口与PC扩色

当前FPGA色号6位，PAL_N及调色板计数8位，PC按单字节像素／色号解码；1437色不能仅修改PAL_N。11位紧凑色号的一行1280像素至少1760字节，含头部会超过常见MTU下的单包载荷，需同步设计分包偏移、分页调色板、色号宽度和PC重组。不得截成8位后称同色，也不能把近色合并当成已经修好了旧哈希映射。

本轮只完成现状审计与候选编译，未改变网络协议、PC解码或发布旧EXE。1437仅为静态材质色数，全部运行时动态颜色还需一并纳入。用户已允许按需扩色，后续不强制压入56色。

## 复现与状态

运行`python tools/run_new_ui_a1.py`生成资产、四个ROM逐像素验证、字库验证、五个独立综合与两张RTL整图；所有中间产物在temporary/new_ui_a1。`--prepare-only --reuse-assets`只重建输入，不启动测量。

源码、生成资产与输出指纹见[manifest.json](manifest.json)。本轮未改游戏核心、现有story_ui／reference_ui_renderer、正式工程登记或正式bit；新增原型尚未接入主渲染。仍需A2～A6的整合、资源闭合、相关回归与最终布线，不能将本轮称为新UI全部完成。
