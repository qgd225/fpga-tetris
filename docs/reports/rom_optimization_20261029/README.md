## 改动与收益

NEXT 两份与 HOLD 一份预览原本各占一块 18 Kb BRAM，实际只读取 shape_rom.coe 中七种方块的初始姿态。本轮用共享 spawn_shape 函数和寄存器替换这三份预览 ROM；保留原始坐标、零初始化和实际两拍延迟。Playfield、旋转、碰撞及智能提示继续使用原 IP，玩法和画面布局不变。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| LUT | 19135 | 19041 |
| 寄存器 | 7477 | 7546 |
| BRAM（36 Kb 等效） | 49.5 | 48 |
| DSP | 13 | 13 |
| 锁存器 | 3 | 3 |
| WNS | +0.063 ns | +0.335 ns |
| WHS | +0.036 ns | +0.036 ns |
| TNS／THS | 0／0 | 0／0 |

节省 94 LUT 和三块 18 Kb BRAM，代价为增加 69 个寄存器；BRAM 余量从 0.5 增至 2 块。未降低时钟、修改例外约束或裁减素材。
