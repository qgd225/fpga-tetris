# 四模式实施与最终验证

完成日期：2026-10-26。单人无尽、双人无尽、单人闯关、双人闯关已实现，正式故事已同步，最新版 bit 已发布。人工上板、PC 实际收流和试听待用户验证。自动预览不等于实机截图。

## 实际交付

- 四入口分别对应 `(duo,campaign)=(0,0)/(1,0)/(0,1)/(1,1)`；闯关先选船，四关全部开放。选关采用机械菜单的三项滚动视窗，四项均可到达，保留可读字号。
- 两种无尽越过旧 32／40 行终点仍继续，最高速持续，八段核心以呼吸表示运行；只有实际顶出进入失败结算。
- 四关参数统一来自 `assets/game_modes.json`。单人残骸总数 25／39／54／70，双人 31／48／66／85；第一关 HALF 教学阈值 13／16。其余默认阈值为向上取整的 40%。
- 64 套模板经几何检查、去重和镜像配对；每关每人数八种不同图案。16 位 LFSR 每局推进一次，零种子回退，加载完成后才允许开局。
- 残骸随真实消行压缩，计数与掩码一致；核心独立累计储备，LOCKED/HALF/ONLINE 与速度分开。全程累计，可清骸同批达标直接成功。
- 公共批次计分保留旧倍率，分数与消行六位饱和 999999，时间饱和 99:59 后继续游戏。暂停、结果快照、重试、下一关和模式切换均清理对应旧状态。
- HUD、残骸、核心三态、结算副标题和选项均接入实际渲染链；无尽无任务胜利对白。增加半功率／上线／拆除提示音，不新增配音素材。
- PC 协议保持兼容，完整画面使用同一 56 色调色板。首版不增加独立 SHIP／DEBRIS 元数据面板，相关数值直接在画面中显示。
