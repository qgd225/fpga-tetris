## 实现与覆盖关系

- `ui_material_atlas.v`：三拍共享ROM，直接描述符→局部／直接色号图案→RGB及遮挡标记。15个素材变体共5813个8×8描述符；多色图块共用RGB表，短尾存储分开，避免按完整二次幂深度浪费BRAM。
- `ui_mission_layer.v`：三拍材质寻址与船况轨条、核心八段／储备液面、侧光及阶段环的动态合成。LOCKED六圈铁索使用独立前景位，压在电芯与溢光之前；八段充能仍由真实输入控制，琥珀色保留为机械底座。
- NEXT/HOLD与重点模块共用一个材质读取端口。`ui_basic_layer.v`通过外部材质输入取得面板RGB，不再额外实例化A2图集。P1/P2肩部、边缘三角与原方块／薄X残骸均保留。
- 闯关导管使用完整的单人底材，双人时由P2面板覆盖。整图对照曾定位到单人会露出的150个导管边缘像素，已修正；面板以外的两种底材相同。无尽不请求导管材质。
- 已接入区域从正式预览skin中填成洋红诊断洞，独立对照器使用未挖洞的A2材质。最终画面一致可验证新路径实际供图，避免旧底图掩盖接入遗漏。`reference_ui_renderer.v`已移除旧动态材质ROM读取。
- 保持`reference_ui_renderer`四拍、`story_ui`共五拍，没有改动坐标、游戏规则或模式参数。

剩余船壳、菜单等仍依赖五bank大预览ROM；它们还没有完成整机硬件落地。这轮的局部可综合模块与整张RTL审核图不能替代整机容量、布线或上板验收。
