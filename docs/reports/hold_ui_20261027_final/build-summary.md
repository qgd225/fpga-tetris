# 无尽供能与 HOLD 存取、UI 调整实施报告

日期：2026-10-27。计划书：[无尽供能与 HOLD 存取、UI 调整计划书](../../计划书/无尽供能与HOLD存取_UI调整计划书.md)。

已完成代码、生成资产、故事与核心规格同步；最终 15 组功能回归及整机布线通过，正式 [bit/Tetris.bit](../../../bit/Tetris.bit) 已更新。实际画面、手感、难度、PC 收流与试听按用户要求交用户上板验证，本轮没有生成真实 RTL 场景预览。

## 实现结果

| 项目 | 本轮行为 |
| --- | --- |
| HOLD 存入 | 空槽时存入当前块并使用 NEXT；保留每块一次、单人 3／双人 2 次落定和至少 2 秒的存入条件 |
| HOLD 取出 | 槽内有块时为按键玩家预约，不受存入冷却限制；本人再按取消，他人不能抢占；同拍轮换优先 |
| 预约交接 | 当前块真实落定、锁定写入和消行压缩结束后交付；不消耗 NEXT、不交换当前块；领取后清槽且只生成一次 |
| 预约寿命 | 未预约仍为 30 秒；预约期间冻结原余量，取消恢复原余量，暂停／重开／终局处理旧状态 |
| HOLD 界面 | 固定三个条件格：本块、块数、时间；边框／小箭头／P1 或 P2 表示预约，不增加冷却面板 |
| 无尽供能 | 初始 90／上限 150，每秒耗 1；正数批次 `24+12n+(n==4?24:0)`，1／2／3／4 行为 36／48／60／96；仍每 45 秒升档 |
| 闯关记功 | `n+(n==4?2:0)`，任务进度、目标与核心使用同一记功；当前共用速度路径也使用记功，实际行数只供内部统计 |
| 胜利评级 | S：平均批次≥3 且每行≤12 秒；A：≥2.2 且≤18；B：≥1.5 且≤28；依次取同时达标的最高级，否则 C |
| 结算字段 | 胜利显示 CHARGE／TIME／RANK／AVG BATCH，无残骸剩余；失败显示 CHARGE／TIME／DEBRIS，无评级或平均批次；两页均无实际消行总数 |
| 任务框 | SHIP、CHARGE 当前记功／目标、DEBRIS 剩余集中；充能增加、残骸减少，独立完成后标签与数字划线；闯关底部只留 TIME |
| 双人布局 | 保留两侧 NEXT；P2 NEXT 下为核心与闯关 SPD；单人 HINT 位于核心旁，双人隐藏 |
| 智能落点 | 单人闯关有效期 12 秒，剩余／上限、可用／已消耗／尚未开放位置和有效期短条分开；无尽仍不限次且不自动关闭 |

三格第一项对应显示的玩家：预约中显示预约者，否则显示最近提出 HOLD 请求的玩家，新局默认 P1。已落定并进入交接的预约不再取消，防止产生无块状态。消行后的交付等待引擎退出写入与压缩，并连续稳定后执行；等待期间不允许预约玩家操纵旧活动块，另一玩家保持正常协作规则。

本轮按用户选择保留恰好四行的奖励公式，没有改为按完整四行组奖励；5 行及以上不获得该额外加成。15／5 单位预警、45 秒升档、各关目标和残骸模板版本 2 均保持原值。供能平衡是否合适由上板试玩确认，未把计划中的满储备占比宣称为已达标。

## 功能验证

[功能回归汇总与测试输入指纹](functional-summary.json)：最终同一版硬件源码的 15 组全部通过，运行期间输入无变化。

分组：duo、frame_duo、level、sound、input_route、net_keyboard、horizontal_repeat、hold_gesture、solo_hint、rgb_palette、lutram、optimization、story、game_modes、rhythm。

| 重点检查 | 结果 |
| --- | --- |
| 供能／时间／提示／冷却 | RHYTHM 47 项通过；初值、14 位容量、20 行大批次、四行奖励、归零救援、暂停提交、12 秒保持等边界通过 |
| 预约控制 | 预约不受冷却限制、取消不刷新寿命、对方不抢占、本人落定才交接、忙时及暂停等待、仅一次取出、未预约到期通过 |
| 真实引擎交接 | 真实 ROM 与正常输入下单人、P2 领取 P1 暂存块、五个 I 块真实消一行后交接均通过；NEXT 保持，落定块保留／消行压缩真实执行 |
| 记功与评级 | 四行只奖励一次、暂停提交保留、实际值与记功分离、S／A／B 精确边界、超时直接归 C、平均批次显示通过 |
| 界面功能字段 | 两侧 NEXT、任务描述、完成划线条件、单人额度／双人隐藏、胜负字段分路通过；只查控制与字段，不生成场景画面 |
| 无尽连续运行 | 341 秒、231 块、42 个真实消行批次／42 行，最低储备 4966 tick，越过 315 秒后保持第 8 档运行 |
| 残骸 | 64 套全部真实引擎清空，HALF 可达，逐步掩码及剩余数量匹配见证；几何未改变 |
| 存储／颜色 | RAM 接线、192 位元数据、共享 56 色及原有输入／计分等功能回归通过 |

引擎交接与无尽见证使用按 600 符号时钟／秒、60 Hz 有效 tick 同比缩放的生产规则参数，80 ms 锁定、约 267 ms 着地检测、85 ms 消行步长；控制明确的后续来块序列，不强改场地、活动块或碰撞结果。原双人随机扰动测试改为已知输入的精确比较，消除八时钟随机采样窗口的偶然失败；正常 NEXT 推进断言仍保留。

本机入口为 `python tools/run_functional_regression.py`，按规则依赖本机 `temporary/sim/` 中对应运行脚本与参考数据。工具已与 `tools/生成bit.bat` 的完整构建入口衔接，报告记录实际执行分组；不强制旧入口中的画面遍历、音频逐样本或 TMDS 专项。
