# 双来源双人控制交付（2026-10-31）

两组GPIO与两组PC键位已实现并发布。P1使用原引脚或WASD＋Q，P2使用新增引脚或方向键＋小键盘0；支持同电脑双人、双引脚双人和正反两种混合组合。单人兼容原方向键。Enter／小键盘5开始暂停，Esc直接返回，F12／小键盘9复位。具体接线和协议见[说明](../../技术说明/双来源双人控制.md)。

同一玩家先合并稳定电平再生成动作边沿，防止单来源释放造成误硬降。双人HOLD统一按下执行，单人保留短按松开与长按提示。新类型5包收齐后同时提交P1/P2，兼容旧类型3；残缺、失焦、退出及超时不产生误硬降或短按HOLD。菜单接收两组来源，开始暂停合并电平，Esc不遗留确认锁态。
