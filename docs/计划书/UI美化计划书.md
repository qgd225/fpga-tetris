## 3. 对具体代码的改动

### 3.1 统一颜色/字模资产

修改 `assets/story_ui.json` 和 `tools/build_story_assets.py`。保留现有8×12字形和2048字节共享ROM，追加铭牌、维护、重试等固定短文本。新增1倍8字距、2倍16或24字距、3倍32字距和维护小字10字距模式，复用唯一 `hud_text`，所有glyph坐标/valid/ink同拍。小常量除3/5用6bit查表，不引入DSP；计入整机实测成本。

类型本色适当降饱和，保留上左亮/下右暗1px切边。owner青/粉，幽灵同类型轮廓，提示白色内框；空像素回场地底色或预览面板底色，不能漏出星空。琥珀用于待修和能量；严重告警只用危险带、核心警戒齿和结果状态条。

同一资产生成器同步输出 `story_palette.vh`、`rgb_to_palette.v` 的无碰撞投影ROM、`net_screen_tx.v` 的56项PAL表、`tools/net_screen_view.py` 默认表。包结构、索引宽度和HDMI协议不变。检查56色往返，不默认为旧哈希仍有效。

### 3.2 卡座与四边机械场地

在 `story_ui.v` 的前景几何中替换原margin/next_border/hold_border：
- 内容锚点NEXT1(176,200)、NEXT2(992,200)、共享HOLD(176,376)均96×96，不挪内容。
- 外板112×112，左上(168,192)/(984,192)/(168,368)，暗底+上左内影+下右细线；无闭合亮边。
- NEXT标题y156、HOLD y332，2倍字形、stride24；分隔线y180/356；玩家8×8色标置标题侧，HOLD共享双4px色标；删除底部孤立粉白条。
- 场地全部使用暗底，24格距中心2×2点，删除连续网格线。
- 六像素外槽分外1/中4/内1；顶部3夹爪，左10处48间距刻度（主刻度加长），右4端口，底45度排线（双人可数≥20处），四处4×4铆点。
- 身份铭牌y634..646：`CONTAINMENT 07` 与 `24X20`/`20X20`；左维护小字 `CORE-07`、`PWR 4200V`、`EVA ONLY`。

### 3.3 阶段与可读性

阶段文字 `(field_x,72)`，2倍/stride24，最长12字占288槽。SPD标签 `(field_x+304,80)` 1倍，值n/8 `(field_x+336,72)` 2倍；最右小于800，不与通信框相交。进度条y106..110，按8个已修接口填充。LINES目标行在y116..128，TIME保留底部。P1/P2小字y120..132，使用1倍10字距，避开COMMS的下缘120。

COMMS保持 `[800,1248)×[24,120)`，仅voice_busy发声期间出现；成功1.2秒静音演出仍不显示文字。菜单、准备、暂停功能不删。

### 3.4 四阶段能量通路

`story_scene.v` 用4个端口替换旧单轨。端口中心与核心每两段成组对位，端口→短支管→同一汇流竖管→核心底端；按phase逐步接通，当前支路强调、过去支路暗青、未来支路暗槽。消行注能复用charge_left，前12tick显示约200ms单段脉冲沿支管、汇流和底线行进，止于核心；没有新增计时器。失败停流但保留已修结构。

`core_renderer.v` 保持32px段距，8段清晰可数：未修暗槽和小点、已修暗青面+2px亮线、当前琥珀面；最高已修段4px暖顶帽。locked>=6显4对外警戒齿，危险2级转红并增长2px。升点只在无告警/无注能/非结果时运行。顶部接头仍是唯一开合结构。

### 3.5 手套与背景

`assets/story_sprites.json` 同一64×32两位手套格内重画直角/45度指节、掌面、护腕三面明暗，减少卡通圆润感；不扩大4096×2图集。`story_scene.v` 增2px折线系绳和小环点，均在场地外。小行星复用现图集，不新增行星细节。船壳结构线克制，stage2/3更亮，与四支路和核心变化共同标示阶段。

### 3.6 结算

框位置不变：暗填充、内影、4px成功白/失败红状态带，无亮闭合框。标题3倍字形，成功x420/失败x500，y264；模式1倍y312，分隔线y336。SCORE/SPD/LINES/TIME四行y344/376/408/440，标签灰、值白、统一右缘832；零分显示“-”。`CORE n/8 SEALED` y496，`PRESS SWITCH TO RETRY` 为21字符，168px宽、x556/y544居中，约1秒两档亮度。

仅压暗场地方块材质（本色/高光转现有暗色），不压核心、仪表、刻度、铭牌。保持结果业务、失败已修进度、成功静音时序。切换开关文案采用现有硬件SWITCH，不使用字库没有的[BTN]占位符。
