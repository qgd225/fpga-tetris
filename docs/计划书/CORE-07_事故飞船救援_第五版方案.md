# CORE-07：事故飞船救援，第五版

> 场景后续明确为穿太空服在船壳外操作系统、收集能量碎片修复核心。最新设计见 [舱外核心修复：第六版方案](<D:/vivado_project/Tetris/docs/计划书/CORE-07_舱外核心修复_第六版方案.md>)。本版保留左右 NEXT 和右上角通信布局讨论。

日期：2026-10-24。状态：方案与像素参考图，未接入 FPGA，未修改 RTL。

本版取代“最后一班接驳艇／人员撤离”主线。沿用四段剧情、八档速度与单人／双人有限目标的规则，视觉按用户提供的当前运行截图收敛：少量像素块表达行星和飞船，少量舱板线与管线表达机械感，细节仅作点缀。

## 1. 故事改为事故飞船救援

一艘飞船发生能源回路故障，失去主动力并出现姿态异常。玩家接管 CORE-07 救援终端，通过能量调度和旁路重构，帮助事故船恢复稳定、完成脱险。

方块是待重构的能量单元；完成一行表示接通一段有效旁路，释放过载并推进救援。堆叠危险表示救援终端的处理能力接近上限。单人是一名操作员，双人是两个操作席共同维护同一条救援链路。

| 剧情／速度 | 故事目标 | 简约图形表现 | 右上角通信示例 |
| --- | --- | --- | --- |
| 01 LINK／1～2 | 建立连接，确认事故船故障 | 飞船倾斜、引擎熄灭；供能线有断点，少量故障标记 | `MAIN POWER IS DOWN.` / `REQUESTING RESCUE LINK.` |
| 02 ISOLATE／3～4 | 隔离泄漏支路，接入旁路 | 飞船周围出现接管定位框；故障支路切断，主供能线连通 | `LEAK ISOLATED.` / `BYPASS IS HOLDING.` |
| 03 RESTART／5～6 | 重启动力，恢复姿态控制 | 船体回正、引擎出现短喷焰；供能母线出现有向脉冲 | `ENGINES ARE BACK.` / `STABILIZE OUR ATTITUDE.` |
| 04 ESCAPE／7～8 | 完成航向与最终点火供能，协助脱险 | 危险边界、航向箭头和更强喷焰；保持待最终点火状态 | `COURSE LOCKED.` / `READY FOR THE FINAL BURN.` |

通关才触发最后点火、飞船驶离危险区域和成功回应，例如 `WE ARE CLEAR. THANK YOU, CORE-07.`。第 04 段仍然需要有效操作，不提前演出任务已经成功。失败为救援链路失效／终端过载，结算显示真实游戏原因，不添加未经规则支持的伤亡数。

任务量继续按上一版初值验证：单人累计 4／12／24／32 行，双人 6／16／30／40 行完成各段。每段两档，内部速度值 0～7。具体阈值与速度曲线仍需实际试玩。

## 2. 版面调整

双人 P1 的 NEXT 位于场地左侧，P2 的 NEXT 位于右侧，尺寸与场地距离对称。两个预览显示各自真正的后续方块；不是把两份 NEXT 都挤在右边。

左侧大机械装置移除，改为小型预览、简化观察窗和细供能管线。机械感来自边框、板缝、切角和少量接入标记。方块保持彩色大面与短高光，不新增厚灰壳和细密纹理。

当前工程 Hold 为共享状态，本版只显示一份小型 HOLD，以连接符作共享提示；位置暂放左侧 NEXT 下方。不会将其画成两个独立存储槽。

右侧 NEXT 下方保留小型事故船状态窗。飞船使用少量像素块和两三个明暗面；背景行星同样使用少量色块。场地中央不放大型装置、立绘、字幕或事故特效。

概念图以 640×360 原始像素制作，整数放大到 1280×720。双人场地 24 列×20 行，原始格距 12 像素；这是设计参考，不代表工程已更改当前格距或坐标映射。

## 3. 右上角配音对话框

对话框固定在右上角的预留顶部区域，位于 P2 NEXT 上方，不遮挡场地、落点和预览。

只在通信／配音发生时出现，随语音逐句更新，播放结束后收起。最多两行短句，可显示小号说话者与简短信号图形，不需要人物大头像。没有通信时保持空白背景，不长期占据画面。

界面保持英文；字幕与实际配音内容逐句对应。若录制中文配音，使用对应英文译文，不额外扩写任务说明。语音语言和最终句长在录制前落实。阶段图展示对话框是为了评审位置，并不表示每段全程常驻。

## 4. 阶段与危机感

阶段变化由事故船状态和供能线路表达：倾斜失动力 → 旁路接管 → 回正且恢复推力 → 航向锁定、等待最后点火。阶段数字只是辅助。

危机反馈保持简约：故障支路的少量闪断、红色断点、局部泄漏和有限的警戒标记；不增加满屏火花、浓烟或复杂背景插画。实际堆叠危险仍由场地顶部清楚提示，消行救回后退去。

声音由事故船 AI／驾驶员的短通信、设备接入、泄压与引擎重启组成。左右受阻采用克制的机械禁止音。最终成功后解除警报，让声音与画面明确恢复稳定。
