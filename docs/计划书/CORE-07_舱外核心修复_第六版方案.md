# CORE-07：舱外核心修复，第六版

> 核心轮廓与画风已进一步修订，见 [简约科技风：第七版修订](<D:/vivado_project/Tetris/docs/计划书/CORE-07_简约科技风_第七版修订.md>)。以细长能量脊和少量导流结构突出科技感；锯齿装饰仅为候选。本稿的舱外修复故事、太阳系背景和布局规则继续适用。

日期：2026-10-24。状态：故事、布局和像素参考，未接入 FPGA，未修改 RTL。

## 1. 玩家在哪里、在做什么

时间设定在遥远未来。玩家穿着太空服，位于事故飞船的外壳表面，在暴露的维修口附近运行 CORE-07 修复系统。系统以俄罗斯方块的形式捕获、整理能量碎片：对齐碎片、组成完整行，完成一段有效重构，将能量注入船载核心。

画面采用第一人称：底部能看见压力手套，边缘有安全系绳、船壳板缝和维修口；中央是投影／舱外终端；右侧是正在修复的核心。背景不再是舱内控制室，也不以屏幕中另一艘小飞船的状态窗作为主要叙事。

## 2. 背景：简约太阳系远景

保留低细节的像素风：少量星点、以土星等太阳系行星为原型的简化轮廓、少量太阳和轨道导航提示。参考图以土星作为远景主物，不在四个短任务阶段中任意切换到不同星球。

太空用较明亮的蓝色层次；前景船壳用浅灰蓝大色块和少量线条；场地保持稳定深蓝。避免复杂星云、巨大密集插画或满屏行星。地点感由少量太阳系特征建立，不抢占方块和核心的注意力。

## 3. 核心为有结构的柱式装置

核心不是平面进度条。它有装在船壳维修口里的底座、分节护壳、内部悬浮能量晶片／能量束、若干可闭合的导流环，以及少量磁悬支撑点。柱形轮廓保持易读，细节采用少量像素块和明暗面。

八个内部能量单元与八档工作进展关联；四大阶段同时改变护壳、导流环和能量束状态。少量数字用于确认，玩家主要通过核心外观理解修复进度。

| 剧情／速度 | 修复工作 | 核心外观 | 通信示例 |
| --- | --- | --- | --- |
| 01 RECONNECT／1～2 | 建立核心连接、确认破损 | 护壳错位，上方导流环断开；仅底部少量能量单元活动，局部泄漏 | `CORE LINK ESTABLISHED.` / `THE HOUSING IS DAMAGED.` |
| 02 REBUILD／3～4 | 重构碎片、修复外壳与旁路 | 错位装甲逐步复位；下半导流环闭合，能量通路向上延伸 | `FRAGMENTS ARE ALIGNING.` / `KEEP THE BYPASS STEADY.` |
| 03 STABILIZE／5～6 | 建立磁约束、稳定能量束 | 导流环对称闭合；能量晶片稳定悬浮，多段核心点亮，泄漏停止 | `CONTAINMENT IS HOLDING.` / `KEEP FEEDING THE CORE.` |
| 04 RECHARGE／7～8 | 完成最后能量补充、恢复核心输出 | 主要能量束贯通，最后单元处于充能状态，顶部和接口等待最后锁定 | `FINAL CHAMBER CHARGING.` / `HOLD IT STEADY.` |

实际通关后：全部八单元稳定工作，导流环锁定，核心恢复正常输出；飞船姿态／动力恢复，并出现短回应 `CORE STABLE. POWER RESTORED.`。

参考帧中 SPD 表示正在进行的工作档位，`5/8 LOCKED` 等表示已完成锁定的单元，二者不必相同。最终档位开始不等于任务完成，最后一个单元需实际达标后锁定。

## 4. 四段八档与玩法的关联

沿用有限目标初值：单人累计 4／12／24／32 行，双人 6／16／30／40 行完成各段。每段两档；速度内部值 0～7。任务和速度最终按试玩调整。

每次有效消行后，短能量流由终端进入核心；阶段达成后，核心结构真实改变并保持。一次消除多行跨过多个阈值，成果全部保留，不补播过时的中间通信。动画不阻塞输入，也不引入新的操作按键。

失败对应修复阵列过载或失去核心约束，仍由真实游戏结束条件触发；正常升级不是损坏加重。随着修复推进，断裂、泄漏和错位应逐步消除；最后充能的紧张感来自能量集中与短机械负载反馈，通关后恢复平稳。

## 5. NEXT、HOLD 与语音字幕

P1 NEXT 在左，P2 NEXT 在右；共享 HOLD 只显示一份。左侧不恢复大幅占位的装置。核心位于右侧 NEXT 下方，手套与底座均不遮挡场地和幽灵落点。

对话框只在语音通信播放期间出现，逐句同步，结束后收起。最多两行英文字幕，小号说话者即可，无需常驻大头像。默认四阶段参考图完全隐藏对话框；另给出有通信的单幅参考，展示它在右上角的实际位置。
