# CORE-07：简约科技风，第七版修订

> 用户认为此版整体仍偏卡通，最新画风参考见 [工业科幻视觉方向：第八版](<D:/vivado_project/Tetris/docs/计划书/CORE-07_工业科幻视觉方向_第八版.md>)。本稿保留核心轮廓比较记录。

日期：2026-10-24。状态：造型与布局参考，未修改 RTL。

## 方向

以简约科技感为首要目标。保留舱外第一人称、太空服手套、太阳系远景、左右 NEXT 和语音出现时才显示的对话框。造型采用清楚的线条、少量色块和精确的结构关系，降低圆润、玩具化的感觉，材质不过分写实。

核心改为细长能量脊。宽底座、圆润能量珠、大环和厚护壳不再作为主体；能量通道、导流边框、刻线与接口构成主要外形。用户提出的“细条周围锯齿装饰”是方向示例，不作为必须采用的模板。

## 三种轮廓候选

| 候选 | 造型 | 取舍 |
| --- | --- | --- |
| A / FIN EDGE | 细能量条加短散热齿边 | 能表现硬件感，但重复齿边可能偏硬、偏密，保留比较 |
| B / FLOATING RAIL | 细能量条加断续悬浮刻度轨 | 更轻、更抽象，适合减少装饰占位 |
| C / DUAL SPINE | 细能量条、断续双轨、三个错位接入点和小接口 | 暂用于整体参考，兼顾结构感与留白 |

整体参考先采用 C，属于可评审候选，尚未确定最终美术。核心缩窄后释放右侧空间，保持方块和场地的视觉优先级。

## 四阶段的表达

修复故事和四段八档沿用第六版。核心通过少量轨道错位、接口断开、重新对齐、连接闭合和能量束贯通表达修复：

1. 建立连接：上部导轨错位，局部断点，低能量活动。
2. 重构：导轨对齐，下部接口逐步连通。
3. 稳定：双轨和主要接口闭合，能源流稳定。
4. 充能：能量脊贯通，最后单元完成充能后进入正常输出。

静态图用于比较轮廓。后续阶段区分还需短滑移、断续变稳定的能源脉冲等有限动效，不通过堆砌大量零件制造区别。
