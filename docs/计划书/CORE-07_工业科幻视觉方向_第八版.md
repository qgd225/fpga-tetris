## 本轮方向

采用精密工业科幻界面：冷灰／钢蓝材质、细线、硬边、明确切角、克制的青色运行提示和琥珀充能提示；文字采用清楚的技术无衬线字形。降低粗像素字、软塑料配色、圆钝手套和玩具化轮廓。

背景仍简洁，以少量船壳结构和安静的太阳系远景建立地点感。参考图中的材质与紧固件属于概念表现，正式像素资产应进一步控制细节，不默认照搬全部纹理。

舱外修复故事沿用第六版：太空服第一人称操作修复终端，重构能量碎片恢复飞船核心。保留单个宽共享场地、左右 NEXT、一份 HOLD、细长能源脊；没有语音时不显示对话框。

细长核心通过窄能源通道、断续导轨、小接入结构和刻线表达精密设备感。四段八档的规则继续有效，本图仅展示第三阶段的整体气质，不代表四阶段图已经同步重画。
