# 第14轮：文字、信息栏、铁索与左上对白

本轮统一运行时文字与数字为同一套5×7字形，同组顶栏标签、数值、百分比对齐底线；P1/P2、NEXT/HOLD、SPD、TIME也使用同一字形。保留上一轮P2与P1同形的凸出肩部。

阶段信息栏移至P2 NEXT下方空区，圆环在上、名称在下，四阶段由下向上推进。无尽的储备信息栏同样左移，继续不显示导管。LOCKED时核心柱增加从上到下连续六圈螺旋缠绕的铁索与锁头，背面链环由柱体遮挡；HALF、ONLINE及成功时不显示铁索，仍读取原有八段状态，琥珀底座不占充能段。

左上对白接入现有comms_visible/comms_id，沿用七条对白内容及触发条件；游玩画面中显示在场地左上角，覆盖层不改变方块或游戏状态。本轮固定输入只用于展示，未宣称验证触发时序。
