# 双人闯关 UI 第1轮 RTL 审核图

本目录为当前正式渲染源码经 Vivado XSim 2018.3 输出的RGB帧，不是生成式效果图，不是素材合成图，也不是上板照片。测试台以固定UI状态驱动实际 `story_ui.v` 和 `reference_ui_renderer.v`；PPM转PNG不改变像素。

场景：DUO CAMPAIGN、SHIP 02、CHARGE 15/35、DEBRIS 18、HALF三段、阶段REBUILD、TIME 02:18。场地24×20、槽112×112；普通幽灵是显示夹具的固定位置。

用户已指出该轮核心柱与参考不同，后续按第2轮继续修改。此图绑定的是生成当时的源码及材质指纹，不能当作后续工作区源码的最新画面。指纹与未改动游戏模块清单见 `manifest.json`。

本轮只运行编译、展开及帧导出；按用户要求没有复验、总检测、综合、布线或新bit。正式 `bit/Tetris.bit` 仍是改动前版本。按流程等待用户看图反馈，不宣称该UI已上板验收。
