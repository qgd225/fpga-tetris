# 双人闯关 UI 第2轮 RTL 审核图

依据用户再次明确的两张来源图：图一的管道、核心及刻度；图二的船况头、P1/P2 NEXT及共享HOLD。原件分别保存为 `assets/reference_ui/source_core_pipe.png` 和 `source_header_panels.png`，摘要写入素材清单。

本轮只改渲染和素材制作：

- 船况头整块使用图二的实际像素；实时记功、残骸、百分比与船号由现有参数覆盖，图中标签不作为游戏常量。
- NEXT/HOLD使用图二面板的切角、标记、字形和凹槽，保持运行槽位为112×112。
- 管道按图一分段沿中心线采样原材质，保持周向粗细；CHARGE右端新增原图套口像素，避免独立色条或脱开的入口。
- 核心及四阶采用图一外壳与字形；舱内八段灯态仍读取现有核心段数；图中示意琥珀舱不变成额外业务段。

真实RTL出图入口为 `Tetris.sim/story_visual/ui_review_tb.v`，固定场景DUO CAMPAIGN、SHIP02、15/35、残骸18、核心3段、REBUILD、02:18。工具为Vivado XSim 2018.3，渲染输出RGB转PNG。源码、材质、测试台和图片指纹见 `manifest.json`。它不是上板照片，也不是生成式效果图。

游戏状态机、落块、计分、供能、HOLD及提示规则源码保持基线 `46745c1` 不变。按用户要求不跑功能复验或总检测，不综合、不布线、不生成bit；当前正式bit仍对应改造前版本。本轮改动未再次提交或推送。
