# 双人闯关 UI 第3轮 RTL 审核图

用户反馈“参考图导管有沟道”。上一轮素材只采样橙管本体附近，遗漏了凹入船壳的沟道。本轮将管路取样扩到两侧完整结构，沿原有中心线保留图一的沟底、内暗边和金属槽沿；管径、路径、六个重点模块及动态数据绑定不另作重排。

入口仍由 CHARGE 轨右端的原图套口接出，下折后作一次轻微错位，沿P2 NEXT外侧连接核心侧套口。只改视觉素材生成，游戏逻辑与渲染数据接口不改。

本目录图片由当前 `story_ui.v` 和 `reference_ui_renderer.v` 经 Vivado XSim 2018.3 输出RGB，固定场景夹具为SHIP02、CHARGE15/35、残骸18、HALF三段、REBUILD、TIME02:18。不是上板照片、生成式效果图或Python代绘帧。局部放大图为RTL输出像素的整数倍裁切。

源码、素材、夹具和帧指纹见 `manifest.json`。本轮仅编译和导出画面，没有功能复验、总检测、综合、布线或新bit。按用户要求出图后等待审核。
