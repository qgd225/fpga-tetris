## 怎么判断放哪

- 设计“应该长什么样” → `最新参考图/`
- 实际“现在长什么样” → `预览图/`
- 还没定 → `候选/`
- 明确不用了 → `废案/`
- 以前用过、后来被更新 → `历史/`（旧基准也在这里）

预览图不自动晋升为参考图；候选图不自动进入最新目录；替换或新增参考图须用户确认。
