# 双人无尽 UI 可编辑 Sketch

本次按用户指定保存到 `D:/vivado_project/Tetris/docs/参考图/Sketch`。仅保存本地，不提交 Git、不推送 GitHub。

## 文件与编辑方法

- `20261027_双人无尽UI_v1.sketch`：在 Pixso 文件导入窗口选择 Sketch 后导入。
- `20261027_双人无尽UI_v1_辅助预览.png`：从 Sketch 内的图层数据绘制，用于快速查看布局，不是 Pixso 截图或真实 RTL 画面。
- `20261027_双人无尽UI_v1_检查.json`：文件哈希、图层统计与结构检查结果。

画布 1280×720，中央场地从 (352,144) 开始，24 列×20 行，每格 24 像素。参考现行 `story_layout.vh` 的尺寸和位置，机械像素风参照 `最新参考图/00_总览_当前UI基准.png`。本文件是对应玩法的可编辑重建，局部装甲、字体与装饰作了矢量化表达，不宣称与 RTL 逐像素一致。

在页面“双人无尽 / 可编辑 UI”展开画板，可分别编辑：星空、船壳与装甲、模式与速度、飞船标识、P1 NEXT、P2 NEXT、共享 HOLD、共享场地、RESERVE、共享成绩与时间。全部图层未锁定；20 个文字层保留原生文字，方块、虚线落点、网格、机械手和装甲均为原生矩形及分组，没有将整幅设计压成图片。小格分组内的“可改色块面”可以单独改色。

字体使用 Consolas，缺失时请替换为本地可用的等宽字体。游戏文字沿用英文；图层名称和维护说明使用中文。原生文本未转曲，Pixso 的字体替换与实际排版仍待手动导入确认。

## 玩法对应

- 共用一个 24×20 场地，双玩家活动块分别用青色和品红色角标标识；双方均有 NEXT 和幽灵落点。
- 共享 HOLD，三个条件格保留；青色边框、箭头和 P1 表示预约状态。
- 顶部八段条只表示速度；示意 TIME 为 02:15，对应 SPD 4/8。
- 右侧连续储备柱表示共享 RESERVE，示意储备为 92/150。
- 底部显示共享 SCORE 和 TIME；累计 LINES 在顶部。
- 不加入单人 HINT、个人分数、攻击条或闯关任务。

数值与方块分布用于设计展示，不是一次真实游戏捕获。此稿尚未确认为新的实现基准；现有 PNG 基准不替换，硬件源码、正式资产和 bit 未修改。

## 重新生成

```powershell
cd D:/vivado_project/Tetris/tools/sketch-editable
node duo-endless.cjs
python inspect-duo.py
```

沿用本目录工具已安装的 `sketch-constructor@1.26.0`、`jszip@3.10.1` 和 Pillow。首次安装依赖见之前小样的使用说明；固定依赖见工具目录 `package-lock.json`。脚本使用原生图层模型并显式 UTF-8 打包，保留中文图层名称，检查图层文字与字符样式一致性。依赖原有许可证和声明保留在安装包内。

重新生成将覆盖这份 Sketch，请将你在 Pixso 中手动修改后的版本另存。
