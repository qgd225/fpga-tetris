## 维护方式

1. 补图：由用户提供或用户明确要求生成；放入本目录后，把对应行状态改为“当前”，填来源和确认日期。
2. 替换：新图先展示并经用户确认；旧图按 `YYYYMMDD_原文件名.png` 移入 [`../历史/旧版基准/`](../历史/旧版基准/)，再更新本清单。
3. 文件名固定为 `NN_名称.png`，不写日期或版本；日期与版本写在清单里。
4. 预览图、候选图不自动进入本目录；未确认前只在清单标“候选”或留在 `候选/`。
