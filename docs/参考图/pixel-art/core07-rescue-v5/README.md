原稿为 640×360，展示稿为整数 2 倍放大，双人场地保持 24×20 格。

## 迭代检查

1. 首轮检查：NEXT 已分左右、对话框已在右上角、左大装置已缩减；小号轮廓字体笔画偏弱，部分英文辨识度不足。
2. 第二轮：换为固定 5×7 位图字形；预览槽缩小并采用深色内底；P1/P2 改为深色字加身份色标；共享 HOLD 只保留一处。
3. 末轮目视检查：字幕无场地／NEXT 遮挡；飞船从倾斜到旁路锁定、回正与推力准备的状态可比较；四幅使用相同局面避免把堆叠变化误认为剧情机制。完整密集堆叠与 M156 实际观感仍需硬件阶段验收。

检查了所有字符存在、文字不越界、四阶段有／无字幕输出、NEXT 对称位置、原图与展示稿严格整数缩放、无半透明像素。每幅约 29～31 个实色。没有从实色数推导 LUT 或 BRAM 实测值。

当前方块使用彩色大面、短高光与小接入标记；星球、船体和背景管线都采用少量色块与线条。右上角字幕仅作为关键通信发生时的示例，不代表常驻。
