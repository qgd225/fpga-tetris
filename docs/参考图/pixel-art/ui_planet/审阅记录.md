# 行星像素素材审阅

使用pixel-art-studio流程，原生64×64、15个可见颜色加透明、左上光源、硬边像素簇，未使用图像模型或重新生成整套UI。

第一轮：圆形轮廓与球面投影成立，海陆、昼夜可读；上方云层过于连贯，下方云带偏厚，判定需修正。

第二轮：拆分两条长云带并增加海湾，去掉横向贯穿的块带；大陆与云层保留曲面透视，夜面向右下收暗。1倍可识别，色阶随同一光源变化；没有棋盘噪声或重复横条。15个可见颜色，无半透明像素、无孤立杂点、无近重复色。轮廓与地表使用统一像素密度；原生PNG和6倍展示图已检查。判定采用第二轮。

正式硬件构建只读取assets/new_ui/blue_planet.png，由tools/build_ui_planet.py编译四位索引与16项RGB表。绘制源build.py需本机pixel-art-studio环境，仅作素材创作依赖，普通工程构建不依赖该技能。右下卫星与已修正的沟道／对白／面板材质保持不变。
