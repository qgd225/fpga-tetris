# 简约科技风核心轮廓

运行 `python pixel-art/core07-tech-v7/build.py`，复用第六版舱外场景，仅替换核心绘制函数。

三种候选：短齿散热边、悬浮刻度轨、双轨能量脊。整体参考暂采用第三种。用户的锯齿建议作为候选，不被当作固定要求。

首轮目视：三种轮廓均已细长化；宽底座、圆形晶片、大环和厚外壳退出主体。双轨方案更适合保留结构关系与留白。

第二轮检查：成功状态的小号文字改为居中；确认左右 NEXT、默认隐藏字幕和舱外构图保持一致；四阶段原稿／展示稿严格整数放大，通信变化局限于右上角预留区域。原稿 640×360，展示稿 1280×720，每幅不超过 64 个实色。

这些是像素参考，不代表硬件显示或时序、资源已经验证。后续阶段辨识还应结合有限的重连、对齐和能源流动效。
